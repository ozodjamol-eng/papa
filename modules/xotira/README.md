# XOTIRA — @XotiraMarkaziBot

Бесплатные посты памяти для «ХОТИРА КАНАЛИ ХЎЖАОБОД» (@XOTIRAXOJAOBOD).

- Человек: /start → фото → «ФИО 1942-2005» (1–2 строки; латиница → кириллица, возраст считается сам) → предпросмотр → ✅ Юбориш. До 5 заявок в сутки.
- Владелец: карточка с фото → ✅ Жойлаш (в канал) / ❌ Рад этиш. Без одобрения ничего не публикуется. /navbat — заявки в очереди.
- Формат поста — как в канале: `Қосимов Қўчқарвой 1942-2005-63 ёш`, внизу `@XOTIRAXOJAOBOD`.
- Сервер: Франкфурт, служба `papa-xotira`, база `/var/lib/papa-xotira/xotira.sqlite3`, токен `/etc/papa-xotira/xotira.env`.
- Установка: `papa-update xotira-install` (владелец вводит токен). Обновление: `papa-update xotira-restart`.
