# XOTIRA — @XotiraMarkaziBot

Бесплатные посты памяти для «ХОТИРА КАНАЛИ ХЎЖАОБОД» (@XOTIRAXOJAOBOD).

- Человек: /start → фото → «ФИО 1942-2005» (1–2 строки; латиница → кириллица, возраст считается сам) → предпросмотр → ✅ Юбориш. До 5 заявок в сутки.
- Владелец: карточка с фото → ✅ Жойлаш (в канал) / ❌ Рад этиш. Без одобрения ничего не публикуется. /navbat — заявки в очереди. Точный повтор — только ❌ Рад этиш (человеку «бор» уже ответили). Размытое фото / нет лица — бот сам вежливо просит другое (владельцу карточка с «✅ Фото нормальное»); в карточке есть «📷 Расм ёмон».
- Фото (19.10): скриншот (строка состояния, поля, кнопки редактора) бот узнаёт сам — человеку подсказка «асл расмни юборинг», а владельцу карточка уже с обрезанным фото. Кнопки владельца: ✂️ Авто-обрезка · 👤 По лицу (портрет 4:5, детектор YuNet) · ✨ Улучшить (мягкий автоконтраст, цвет, резкость) · ↩️ Оригинал · 📎 Своё фото (или ответить фото на карточку). Без кнопки ничего не публикуется. OpenCV — venv `/opt/papa-venv/xotira` (`papa-update xotira-photo-install`); без него бот работает как раньше, без обрезки.
- Формат поста — как в канале: `Қосимов Қўчқарвой 1942-2005-63 ёш`, внизу `@XOTIRAXOJAOBOD`.
- Сервер: Франкфурт, служба `papa-xotira`, база `/var/lib/papa-xotira/xotira.sqlite3`, токен `/etc/papa-xotira/xotira.env`.
- Установка: `papa-update xotira-install` (владелец вводит токен). Обновление: `papa-update xotira-restart`.
