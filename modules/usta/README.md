# USTA — бот заявок «уй ва таъмир» (эксперимент 31.10.2026, 1 неделя)
Владелец: «сделать бота, опрос в канале/группе — кто откликнется, те реальные клиенты».
Путь: услуга (дизайн, таъмир, электрик, сантехник, мебель) → детали → место → фото (необяз.) → телефон → карточка владельцу.
Источник — ссылка `t.me/<бот>?start=<метка>` (xojaobod, davra, ig). Владельцу: `/stats`.
Цифра эксперимента: число заявок за неделю. Установка: Франкфурт, консоль — `papa-update usta-bot-token`. Расход $0.

Объект → м² → стиль → цена; бот принимает `web_app_data` или `/start d_<obj>_<m2>_<style>` и ведёт дальше обычным путём (когда → место → фото → телефон).

**31.10 — пульт владельца кнопками** (владелец: «должен видеть внутренность, без /команд»): у владельца вместо меню клиента — «📊 Ҳисобот · 📥 Аризалар · 🛠 Усталар · ⏳ Текширувда · 💰 Тўловлар · 👀 Мижоз менюси». Заявка/мастер открываются кнопкой; «💰 Тўланди» и «💸 Улуш бердим» спрашивают сумму числом. Старые /stats, /ustalar, /tolandi, /berildi работают как запасные.

**02.11 — регистрация мастера упрощена** (владелец: «мастера жалуются — невозможно оформить»): было 8 шагов (имя, район, опыт, фото лица, фото работ), стало 2 — касб → «📱 Рақамни юбориш» → готово. Имя берётся из Telegram, фото не обязательны. Одобрение владельца ✅/❌ осталось. Добавлена профессия «👷‍♂️ Бош прораб» (подходит к заявкам «Таъмир»).

**02.11 — меню мастера** (владелец: «мастера приводят людей — им самый простой вариант»): одобренный мастер видит свои кнопки «➕ Мижоз юбориш · 📊 Ҳисобим · 🔗 Ҳаволам (QR) · 📥 Буюртмаларим». «Мижоз юбориш»: телефон/контакт клиента → текст или 🎙 голос → заявка на мастере (ref+via, 10%). Мастеру приходит «ваш клиент оставил заявку». Голос принимается и у клиента на шаге «детали». QR — через api.qrserver.com (Telegram сам забирает картинку). В пульте — «👷‍♂️ Прораблар», ссылка `?start=prorab` (1 кнопка).

**02.11 — прораб только по приглашению + команды** (владелец: «если открыть — все станут начальниками»): «Бош прораб» убран из открытого списка профессий; старая ссылка `?start=prorab` отключена. Пульт «👷‍♂️ Прораблар» → «➕ Прораб таклиф қилиш» → одноразовый QR `?start=p_<код>` (1 человек, код в kv), приглашённый прораб — сразу ✅. У прораба кнопки «👥 Жамоам · ➕ Жамоага қўшиш» (QR `?start=t<id>`): мастер → касб → телефон → **прораб сам** ✅/❌ (`ta/tr`), владелец видит уведомление. Заявку, отданную прорабу, он после «Оламан» передаёт своему человеку (`tg:<n>:<id>`). Деньги: клиент от члена команды — 7% ему + 3% прорабу (`TEAM_MEMBER_PCT/TEAM_LEAD_PCT`), от прораба/обычного мастера — 10%.
