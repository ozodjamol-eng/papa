# Дизайн квартир — рабочка (синов, 31.10.2026)
Новое направление владельца: дизайн квартир для местных строителей (цена за м²). Образец конкурента — ANOOR design (Андижон).
- `geo.py` — геометрия квартиры в см (снята из AutoCAD PDF заказчика через PyMuPDF, масштаб 0,70483 pt/см).
- `rabochka.py` — 8 листов A3 на узбекской кириллице: титул, ўлчов, мебель, электр, шифт/ёритиш, пол, эшик/деразалар, изоҳлар → PDF (Playwright, шрифт Inter).
- Исходные PDF заказчика в репозиторий не кладём (личные данные).
Чего ещё нет против ANOOR: привязки розеток к стенам (размеры), шифт по каждой комнате с разрезами, 3D-визуализация.
