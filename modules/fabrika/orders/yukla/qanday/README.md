# «Қандай юклаш» — ролик-объяснение @XojaobodYuklaBot (04.11.2026)
Сценарий владельца: «Видео ёқдими? Қандай юклашни билмайсизми? Ботимиз ёрдам беради» → имя бота → как работает (3 шага) → MP3 → бепул → призыв.
- Голос: главный голос PAPA (SAFO-MARVA-diktor, $asosiy), 23,6 с; паузы раздвинуты склейкой по тишине (голос не растянут) → 27,9 с. Тайминги фраз — timing.json.
- Музыка music_kech (Pixabay) тихо под голосом (−31 LUFS против −16). Субтитры снизу (выше безопасной зоны). Телефон и чат — моушн, без записи экрана (владелец).
- Без OZOD JAMOL и водяного знака — бот нейтральный. Ассеты молнии — ../bolt, рендер — ../render.mjs.
