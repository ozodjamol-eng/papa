# 🎤 shou — движок «Шоу-бизнес янгилик» (шаблон Фабрики №9)

Один код на все выпуски PAPARAZZI × КАТТА ДАВРА. Выпуск описывается заданием `job.json` — код не правится.
Порядок работы — скилл `.claude/skills/shou-yangilik`. Формат задания и команды — в шапке `engine.py`.

- `analyze` — карта исходника (склейки, громкость, цвет акцента).
- `check` — правила владельца 14.11: материал целиком, диктор только на песне (не раньше 4 с), слова артиста не перекрывать,
  в конце песня одна, титров ≤ 5, концовка OZOD JAMOL всегда. Нарушение — ролик не собирается.
- `stills` — контрольный лист кадров. `render` — готовый ролик 1080×1920, 30 fps, < 50 МБ.
- Тесты: `python -m unittest modules/fabrika/shou/tests/test_engine.py` (без ffmpeg).
- Нужно: ffmpeg, numpy, Pillow, шрифт Inter Black (`apt install fonts-inter` или `FONT=путь`).

Этап 2 (не сделан): черновик `job.json` пишет ИИ на сервере, владелец утверждает строки диктора по номерам в пульте,
сборка — GitHub Actions (как дайджесты). Расход 0 $.
