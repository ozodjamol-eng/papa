# Библиотека материалов Фабрики PAPA (08.11.2026)

Зачем: учебная копия earn.edits показала — движение у нас почти на их уровне, отстаём МАТЕРИАЛАМИ (фактуры, предметы, звуки).

- `faktury/` — 15 настоящих фактур ambientCG (CC0: можно всё, без указания автора): бумага ×3, бетон ×3, дерево ×2, ткань ×2, штукатурка, кожа, металл ×2, мрамор. Плюс свои кодом: чертёж, тёмный гранж, зелёная доска, бархат бордо. Наложения (поверх кадра): `nalozh_zerno` (overlay), `nalozh_pyl_tsarapiny` (screen), `nalozh_zasvetka` (screen), `nalozh_poluton.png`; маска `maska_rvanyi_kray.png` (рваная полоса бумаги).
- `zvuki/` — 47 настоящих звуков Mixkit (бесплатная лицензия Mixkit): переходы, бумага, удары, щелчки, клавиатура, глитч, поп, телефон, нарастания. Список — `zvuki/README.md`. Синтетику не используем (правило владельца).
- `predmety/` — 8 объёмных предметов-«наклеек» 1024×1024, прозрачный фон, сделаны КОДОМ в 3D (three.js, студийный свет): телефон с SMS-ссылкой, крючок с наживкой, лупа, щит с галочкой, замок, монеты, конверт, хромированный шар. Новые предметы — дописать функцию в `predmety/js/predmety3d.html` и запустить `node predmety/js/shot.mjs` (нужны three и playwright). Через Flow не делаем (владелец 08.11).

Как подключать в ролик: фон — `<img src=".../faktury/paper_Paper005.jpg">` с наездом камеры; наложения — `mix-blend-mode: overlay/screen`, opacity 0.08–0.25; звуки — ffmpeg adelay по времени перехода, тихо под голос.
