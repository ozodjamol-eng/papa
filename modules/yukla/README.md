# YUKLA — «Хўжаобод Юкла ⚡» (@XojaobodYuklaBot), 03.11.2026
Владелец: «такой же бот для себя» (образец @Chaqqon_Robot). Цель — рост Xo'jaobod City: перед скачиванием подписка на `YUKLA_SUB_CHAT` (@xojaobodcity24).
- Ссылка Instagram / TikTok / YouTube → видео (+ 🎵 MP3, 📢 Канал) + рекламная строка владельца.
- «Память»: каждый отправленный файл хранится как file_id → та же ссылка следующему человеку — мгновенно, без Instagram и прокси.
- Пульт владельца: 📊 Ҳисобот · 📢 Реклама матни · 📤 Рассылка (только после ✅).
- Бренд: имя нейтральное (не OZOD JAMOL) — при блокировке по жалобам каналы и имя владельца не задеты.
- Прокси: `YUKLA_PROXY` (необязательно). Решение о покупке ($5, DataImpulse и т.п.) — после `yukla-probe` и 1–2 дней без прокси.
- Установка (Франкфурт, консоль, только владелец): `papa-update yukla-bot-token`. Обновление: `yukla-restart` (авто). Проверка без прокси: `yukla-probe`.
- Бот должен быть админом в канале/группе подписки (иначе проверка подписки пропускается, владелец получает одно предупреждение).
