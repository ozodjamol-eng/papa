# GENPLAN PAPA

Публикации по сетке слотов в несколько каналов: якоря (намоз, дуо), рубрики, рекламные окна, «Кун хонандаси».
План — `docs/PHASE3.md`. Сетки — `config.toml` (Хўжаобод: «Пульс» + реклама; PaparazziUZ: 10 постов в день).

- `genplan/plan.py` — план дня: рубрики с запасными, реклама, свободное окно → лишний материал (не самопиар), статусы ✅⏳⚠️💰.
- `genplan/text.py` — убрать чужие подписи, добавить свою; рекламу не трогать.
- `genplan/publish.py` — BotPublisher (канал, от имени канала) и AccountPublisher (группа, анонимный админ — от имени группы).
- Ядро: `core/schema_v2.sql` (материалы из хаба, слоты публикаций, реклама по окнам).

Состояние: логика и публикаторы готовы и проверены (13 тестов). Дальше: хаб PAPA HUB → материалы, служба-планировщик, бот владельца, теневой режим в PAPA TEST.
