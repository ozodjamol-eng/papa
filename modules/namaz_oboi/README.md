# Намоз обои (03.11.2026)
Шаблоны владельца (NAMOZ_EDITOR, 5 стилей, Android 1080×2400). Владелец: «5 материалов кидаются вместе с готовым текстом — человек сам выбирает».
- Время — из «Намоз маркази» (/var/lib/papa-namaz/namaz.json). Рисует `render.py` после каждой выгрузки (papa-namaz-export, ExecStartPost), только если время изменилось → /var/lib/papa-namaz/oboi/<день_время>/ + CURRENT.
- Кнопка «🟢 🕌 Намоз вақтлари» в Юкла: альбом из 5 картинок + готовый текст (первый раз загрузка, потом file_id — мгновенно).
- Шрифт DejaVu Serif Bold (Georgia из шаблона на сервере нет); дата сама подбирает размер, чтобы влезть в плашку.
