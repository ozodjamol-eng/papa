# Pult — управление и наблюдение (бывший NEXUS V2)

Снимок кода, работающего на Франкфурте и Лондоне на 2026-10-14.

| Папка | Что | Где работает |
|---|---|---|
| `gateway/` | шлюз NEXUS V2: очередь безопасных задач, панель, роли owner/ai/agent (релиз `r4-london`) | Франкфурт, 127.0.0.1:8788 |
| `connect/` | NEXUS Connect: OAuth 2.1 + MCP для ChatGPT и Claude (релиз `r3`) | Франкфурт, 127.0.0.1:8789, Funnel `/mcp` |
| `london-agent/` | агент только для чтения: GENPLAN, службы, публикации, ресурсы | Лондон |

Примечание: `gateway/static/index.html` на сервере отличается от этой копии (кнопка «GENPLAN Лондон» на сервере не вставлена). Сверить в фазе 0 при переходе на обновление из GitHub.
