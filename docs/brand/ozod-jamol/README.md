## Урок 01.11.2026: буква «Ў» (владелец поймал на слух)
Клон (eleven_v4, uz) читает кириллическую «ў» как русское «у»: «Ўйлаб кўр» → «Уйлаб кур», «йўл» → «юл», «ўтган» → «утган». Это ошибка — нужен звук «o'».
- Перед озвучкой каждое слово с «ў» переписать в тексте для TTS: короткие фразы — латиницей («O'ylab ko'r.»), внутри строки — через «о» («йол», «отган», «тоғри», «йоқ»). На экране/в постах — правильная кириллица «ў».
- Проверка: faster-whisper medium, language=ru — в слове должна слышаться «о» («Ой, лакор»), не «у» («Убил аккор»). «Уши» (Gemini) этого НЕ ловят — пишут правильное слово по смыслу.

## Урок 01.11.2026: медленнее и без повторов (владелец: «как автомат», «много балки»)
- eleven_v4 почти не слушает `speed` 0.75 и «…» — строки выходят той же длины. Замедляем при сведении: `atempo=0.9` + внутренние паузы строки удлиняем на +0.45 с (резать по середине тишины, слова не трогаем); между строками 2.4 с, перед поворотом и финалом 3.0 с.
