# Фирменная концовка OZOD JAMOL, 2,3 с (26.10.2026)
Логотип OJ в 3D: O и J сходятся (0–0,4 с) → «дзынь» → оборот 360° → сжимается в точку → исчезает. Надпись OZOD JAMOL 0,5–1,35 с.
Звук: «Greanpatch» (Pixabay, SoundReality, лицензия Pixabay — коммерческое использование разрешено, неисключительно) на 0,38 с + вжух сборки и оборота + отзвук на тон выше на 1,45 с.
Три варианта фона из готовых: белая (BG02, O чёрная), чёрная (BG01, O белая), красная (BG03, O белая, J чёрная).
`end3.py -- col=white|black|red res=540x960 spp=16 out=DIR` (прозрачный рендер + ловец теней, ~33 с/кадр) → `snd_gp.py` → `comp_end.py <col>` → ffmpeg.

## Готовые файлы (от владельца 26.10.2026) — вставлять в конец каждого рекламного ролика Фабрики
- `OZOD_JAMOL_KONCOVKA_BELAYA.mp4` — к светлым роликам (Shodiyona, белый фон)
- `OZOD_JAMOL_KONCOVKA_CHERNAYA.mp4` — к тёмным
- `OZOD_JAMOL_KONCOVKA_KRASNAYA.mp4` — к ярким/красным
Склейка: финальный кадр ролика → концовка (музыка ролика затухает 0,5 с, дальше звук концовки). Перерендер не нужен — брать эти файлы как есть.
