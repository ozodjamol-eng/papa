# 3D-концовки OZOD JAMOL (25.10.2026)
Blender (pip bpy 4.2, Cycles CPU) → композ PIL → ffmpeg. 3,4 с, 9:16, голос BAS «Озод Жамол».
1. `anim3d.py -- v=1|2|3 res=540x960 spp=16 out=DIR frames=0-75`: 1 «Сборка в пространстве», 2 «Из стены», 3 «Осколки».
   Камера — DAMPED_TRACK (TRACK_TO с up=Y крутит кадр при взгляде сверху вниз).
2. `snd3d.py V` → sV.wav;  `comp3d.py V` (апскейл до 1080×1920, свечение, надписи, зерно; кадры 76–101 — 2D-наезд);  `enc.sh V`.
Время рендера на 2 ядрах: №1 и №3 — ~25 мин, №2 (стена) — ~60 мин.
