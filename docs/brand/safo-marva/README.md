## Голос — ПОСТОЯННЫЙ (утверждён владельцем 02.11.2026: «однозначно C, взять на постоянный»)
- ElevenLabs, клон диктора из их ролика «Jannatim»: `SAFO-MARVA-diktor`, voice_id `ph7cEBlVHFfCY5GiGvA2`.
- Модель `eleven_v4`, settings: `{"stability": 0.55, "similarity_boost": 0.9, "style": 0.1}`.
- Темп — НЕ параметром speed (v4 его игнорирует) и НЕ растягиванием звука (звучит «компьютерно»),
  а паузами в тексте: многоточие «...», запятые, пустая строка между фразами.
- Без «!» в тексте — иначе голос начинает кричать. Высокая стабильность (0.85–0.9) = плоский «компьютерный» голос.
- Эталон: `golos_C_etalon.mp3`.
