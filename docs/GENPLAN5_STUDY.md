## Ядро доверия местных (переносим полностью)
- **Намоз**: источник — только время, подтверждённое админом (внешние API ошибались до 47 мин). Ввод — одним сообщением, все 5 времён разом, дата в тексте только для показа.
  Публикации: таблица 5 времён за 30 мин до Бомдода; напоминание ровно за 10 мин до каждого намаза; в само время намаза — ничего.
- **Жума**: напоминание за 45 мин; «тихое окно» −20/+35 мин от Пешина в пятницу — ни рекламы, ни музыки, ни развлечений (кроме срочного).
- **Утренний системный блок 07:00**: приветствие (варианты) + погода (open-meteo, бесплатно) + курс ЦБ (cbu.uz) + качество воздуха + картинка-баннер. Данные — раз в день, сбой источника не ломает пост.
- **Якуний пост 22:00** (Муфтий минбари) — отдельный слот.
- **Окно 07:00–22:00**; ночью — мягкий перенос на утро; срочное — исключение.
- **Реклама**: пакеты 1/6/10 дней, 1 показ в день, воскресенье — без рекламы и не засчитывается; кнопки «📣 ЭЪЛОН БЕРИШ / 💬 АДМИНГА ЁЗИШ»; без логотипа и подписи.
- **Пульс канала, защита от повторов, очистка чужих меток, кириллица, подпись**.
- **Правило для агента**: новости выбирает только владелец; агент — только полезное и развлечения; запрет на криминал, смерти, сплетни, «чудо-лечение».
- **Баланс дня**: 4 корзины (ахборот / фойда / ҳаётий / кайфият).
- **Опросы** — шаблоны.
