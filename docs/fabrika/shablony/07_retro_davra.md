# Шаблон №7 «РЕТРО ДАВРА» (12.11.2026, проба: Maxx «Get-A-Way», 1993)
Идея владельца: ретро-рубрика из живых клипов мировых/узбекских хитов с переходами, моушном и надписями, чтобы привлекать взрослую аудиторию.
Код: `modules/fabrika/retro/render_retro.py` (numpy+cv2+PIL, 1080×1920, 3 мин ≈ 4 мин рендера). В начале файла — ARTIST, SONG, YEAR, FACT, границы клипа CY0/CY1.
Состав: заставка (год → «РЕТРО ДАВРА») → клип в рамке «телевизора» (строки развёртки, PLAY закрывает чужое лого в углу, счётчик ленты) →
плашка «КАТТА ДАВРА · РЕТРО» + артист/песня/год → кассета + эквалайзер по настоящему звуку → VHS-сбой на склейках (не чаще раза в 7 с) →
карточки (факт, «Ёдингиздами?») → знак PAPARAZZI UZ поднимается в промежутках (каждые 30 с) → финал «Ўшанда неча ёшда эдингиз? Изоҳда ёзинг».
Правила: год и факты проверять в интернете самому (не из чужой подписи); чужие логотипы в кадр не попадают; звук — только оригинал песни, своих звуков не добавлять;
один ролик на оба бренда (не две версии). Файл для бота < 50 МБ: crf 22, maxrate 1900k. Текст песни на экран не выводим.

## 2-й ролик (12.11): Sandra «Maria Magdalena», 1985 — вертикальный клип во весь кадр
- Запуск с конфигом: `python3 render_retro.py cfg.json [stills]`; cfg: dir, tall, crop [y0,y1], dur, artist, song, year, fact (3 строки).
- `tall: true` — клип выше (1080×1290), плашка счётчика шире и закрывает чужое лого справа сверху («Vintage Clubbing»); артист/песня/год — одной строкой.
- Факт сверен в интернете: вершина чартов в 21 стране.
