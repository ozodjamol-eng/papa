## Шаблон №1 «Живой постер» (утверждён владельцем 26.10.2026)
Плакат, который «собирается» в такт музыке на фирменном фоне клиента:
1. Шторка в цвете бренда с иконкой → логотип клиента сверху.
2. Заголовок в 2 строки «ударом» (слэм), подзаголовок.
3. Смысловой блок: цепочка шагов (например «① РАСМ → ② БОТ → ③ БУЮРТМА» или «ЗАВОД → ЎРТАКАШ ✂ → СИЗ»), печать-бейдж («ДИЗАЙН БЕПУЛ») или галочки.
4. Товары (вырезанные PNG) падают сверху с отскоком/пылью или въезжают сбоку со шлейфом; тряска кадра на ударах.
5. Полоса-слоган → кнопка с телефоном (пульс) → строка с контактами.
6. Удержание финального кадра 2–3 с → **концовка OZOD JAMOL**.

Как делать новый: новый вариант в `series.html` через `series({l1,l2,sub,items:[[картинка,X,низ,ширина,'drop'|'slide',0,направление]]})`; темп `&b=` = 60/BPM трека (быстрый трек — шаг 1,5 доли), фаза = первая доля трека; рендер `rend.py <html> <вариант> video <out> <сек> <фаза> <b>`; музыка — loudnorm −14 LUFS, затухание 0,8 с.
Вырезка товаров — rembg `isnet-general-use`; чужие надписи/водяные знаки — закрыть клоном соседней текстуры, плохо вырезанные фото (фон внутри полок) — не брать.
К каждому ролику — рекламный текст (узб. кириллица): заголовок с эмодзи → абзацы с эмодзи → «Буюртмалар шу рақам орқали қабул қилинади» + номер → крючок → ссылки.
