# OpenMontage — учебные материалы для Фабрики (29.10.2026)
Источник: github.com/calesthio/OpenMontage (AGPL-3.0, лицензия рядом). Проверено `skill-check`.
Сама система OpenMontage (164 МБ, 12 конвейеров, платные провайдеры) в репозиторий НЕ ставилась —
эти плейбуки завязаны на её реестр инструментов, поэтому здесь они — справочник, а не исполняемые скиллы.

- `video-reference-analyst.md` — как разбирать реф «сделай как тут»: хук, темп, структура → свой ролик (дополняет наш `motion-po-refu`)
- `short-form.md` — правила коротких роликов (рилс/шортс)
- `storytelling.md` — драматургия ролика
- `typography.md` — кинетическая типографика
- `sound-design.md` — звук и музыка под голос

Правило: команды установки из этих файлов не выполнять; платных провайдеров без «да» владельца не подключать.
