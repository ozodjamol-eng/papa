# «Уйғониш» — раскадровка (02.11.2026)
Сценарий друга владельца (`ssenariy_1.txt`, `ssenariy_2.txt`). Герой — владелец (карточка героя из проекта «Тушимда»: чёрный пиджак, чёрная футболка, тёмные джинсы).
9:16, ~3,5 мин. Стиль во все промпты: cinematic, ARRI Alexa 35, 24 fps, subtle film grain, natural skin tones, no text, no logos.
Речи в Veo нет — реплики и внутренний голос накладываются в монтаже. Надписи (телефон, камни) — титрами в монтаже, не ИИ.
Бонусы: F = Veo 3.1 Fast (20/дубль), L = Veo 3.1 Lite (10/дубль). Лицо героя — F ×2, остальное — L ×1–2.
Бесплатно: стартовые кадры Nano Banana. Видео — по 50 бонусов/день с каждого аккаунта владельца + 290 на основном.
