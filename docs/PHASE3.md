## Что исправляем
- **Расписание по часам, а не по кругу**: каждая рубрика — в своём слоте (в GENPLAN 5 по часам шла только реклама).
- **Несколько каналов**: у каждого своя сетка слотов (Xo'jaobod — «Пульс»; PaparazziUZ — шоу-бизнес и музыка).
- **Общее ядро**: материалы, публикации, реклама — в базе PAPA (PostgreSQL), а не в отдельной базе бота.
- **Просмотры**: 1ч / 6ч / 24ч по каждому посту (читает Разведка) → цифры для цены рекламы STANDARD/PRIME.
- **Статус дня**: ✅ готово / ⏳ в очереди / ⚠️ нет материала / 💰 реклама — по каждому слоту.
