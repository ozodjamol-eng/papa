# 🏷 Политика маркировки контента PAPA (01.11.2026)

Владелец: «ты перестал маркировать… пересмотреть политику маркировки, сделать одного агента, который только этим занимается».
Агент — **МАРКИРОВЩИК** (`modules/genplan/genplan/marker.py`). Одна работа: наша метка на видео и фото перед выходом.

## Почему метки не было
1. 23.10 утро «Хайрли тонг» переведено на готовые видео «как есть» — вместе с дешёвой надписью убрали и метку @.
2. Посты из пульта, складов и источников уходят копией (copyMessage) — файл не меняется, метки на видео не было никогда; @ стоял только в тексте.
3. Метка жила только в Фабрике (ссылка → видео) и в наших дайжестах. Единой политики не было.

## Правила
1. Метим: каждое одиночное видео и фото во всех трёх каналах — @юзернейм СВОЕГО канала (КАТТА ДАВРА `@kattadavrauz`, Хўжаобод `@xojaobodcity24`, PaparazziUZ `@ozodjamoll`).
2. Утро «Хайрли тонг» / «Жума» — тоже метим, но только @ (никаких заголовков на видео — правило 23.10 «дёшево» остаётся).
3. Видео — метка «подъём»: снизу по центру, поднимается и тает до середины кадра, раз в 15 с. Фото — маленькая полупрозрачная в правом верхнем углу. Шрифт жирный.
4. Не метим никогда: рекламу клиентов, «Муфтий минбари», уже наше (Фабрика, дайжесты), альбомы (пока).
5. Качество не режем (crf 20); больше 50 МБ — лёгкое сжатие только для отправки.
6. Файл больше 20 МБ бот скачать не может → пост выходит без метки, Штаб отмечает это в отчёте.
7. Банк (KATTA BANK) хранит чистые видео без метки — метка ставится при выходе, своя для каждого канала.

## Как работает (включено 01.11, «да, включай всё»)
- Банк (KATTA BANK) — общий и чистый, по направлениям. Метка в банк НЕ ставится.
- Маркировщик (отдельный цикл в papa-genplan) берёт посты, которые стоят в сетке на 30 ч вперёд, и 📦 запас каналов,
  по одному: скачивает (бот до 20 МБ; больше — через аккаунт PAPA), ставит @ своего канала, кладёт на полку
  «<канал> · ГОТОВО» (частный канал аккаунта PAPA, боты канала — админы). Пост потом выходит копией с полки.
- Не успел к выходу или не смог — пост выходит как раньше, без метки (сетка важнее). Две неудачи на пост — больше не трогает.
- Посты без своего текста не метятся (подпись ИИ делает при выходе по исходному файлу).
- Утро «Хайрли тонг» из пула — метка ставится при подготовке утра.
- PaparazziUZ — метка на то, что выбрано к выходу (тот же механизм). Файлы >20 МБ из пульта PaparazziUZ — пока без метки (бот пульта не видит PAPA HUB).
- Откат: `marker = { on = false }` в config.toml → `papa-update genplan-restart` (Франкфурт).

Статус правила: **основное (core)**. Отменяет часть решения 23.10 («утро без метки-юзернейма»).
