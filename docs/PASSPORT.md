## 0. Схема «Штаб → отделы» (30.10.2026, утверждено владельцем: «да»)
Цель: **Telegram — дом аудитории** (самое лучшее, трендовое, полезное — в одном месте). Instagram/TikTok — источник трендов
и воронка (238K → Telegram), чужие тренды в Instagram не постим.

```
                 🧠 ШТАБ (мозг)
   план дня → задачи отделам → проверка → отчёт
                       │
   ┌──────────┬────────┼────────┬──────────┐
 🔭 РАЗВЕДКА  ✍️ РЕДАКЦИЯ  📤 ВЫПУСК  💰 БИЗНЕС
```
1. 🧠 **Штаб** (Claude + NEXUS): заказ на материал из сетки (genplan/needs.py → needs.json), раздача отделам, контроль, один вечерний отчёт владельцу в боте ШТАБ.
2. 🔭 **Разведка**: тренды Instagram/TikTok → для Telegram; конкуренты Telegram (карта дня); источники (отбор, чистота).
3. ✍️ **Редакция**: у рубрики — главный источник + архив (якорь: свежее → склад, цикл не прерывается); ИИ-редактор — свой текст кириллицей, наш @, без чужих лого.
4. 📤 **Выпуск** (GENPLAN): сетка «час = рубрика», протоколы, публикация, вето 🗑.
5. 💰 **Бизнес**: реклама (ИИ-ассистент → заказ → ✅ → сетка → отчёт клиенту), Фабрика, Воронка.

Упрощение: одна точка управления владельца — бот ШТАБ; пульты каналов — только «бросить пост»; склады = архивы рубрик;
три ХАБа каналов больше не нужны (бросать прямо в пульт). Порядок: неделя 1 — Штаб, якоря, ИИ-редактор ($0);
неделя 2 — Instagram-тренды (парсер ~$10–30/мес, смета отдельно); неделя 3 — бизнес-отдел и отчёты рекламодателям.

**Банк контента — дорожная карта (30.10.2026, идея владельца; «потом, но не сейчас»):**
1. Сейчас: хабы направлений = наш банк. Ничего не выбрасываем — всё чистое копится (смешное, польза, бизнес, мотивация, музыка).
2. Когда аудитория вырастет: свой штамп/водяной знак (@ канала) на видео из банка — механизм уже есть в Фабрике (watermark_video).
3. Интеграция с Instagram: лучшее из банка — в Instagram владельца (с нашим знаком), воронка обратно в Telegram.
4. Потом: банк как продукт — сначала для себя, затем предложение другим (масштаб).

## 1. Цель

**Доход от рекламы.** Всё остальное — средства.

Аудитория уже есть: YouTube (~575 тыс.), Instagram (~238 тыс.).
Её нужно перевести в собственные Telegram-каналы, удержать контентом и монетизировать рекламой.

Главная формула системы:

```
ДОХОД = средние просмотры поста × рекламных постов в день × цена размещения
```

Рекламодатель платит за **просмотры**, а не за подписчиков. Каждый модуль обязан улучшать один из множителей.

## 3. Модули

| Модуль | Что делает | Какой множитель формулы двигает |
|---|---|---|
| **Razvedka** | Читает каналы-источники и конкурентов: время публикаций, просмотры, темы, реклама у конкурентов | просмотры (лучшее время и темы), цена (рыночный прайс) |
| **Voronka** | Комментарий в Instagram → директ → ссылка по источнику → заявка в канал → приветствие бота (с приглашением во второй канал). Директ ведёт на свою страницу-визитку (аналог Taplink) с обоими каналами и кнопкой «обе сразу». Режим «ответ всем» — на любой комментарий, на любом языке; один директ человеку на пост. Следующий шаг: ИИ-ответы в комментариях (узбекский кириллицей), с дневным лимитом расходов | аудитория → просмотры |
| **GENPLAN** | Публикации по плану: рубрики, намаз, слоты, рекламные окна | просмотры, рекламных постов в день |
| **Reklama** | Прайс от реальных просмотров, бронирование слотов, отчёт рекламодателю | цена, рекламных постов в день |
| **Fabrika** | ИИ: пересказ материала своим голосом, хуки, рилсы/Shorts | всё (топливо) |
| **Pult** | Управление и наблюдение: статус, ошибки, обновления с подтверждением владельца; доступ ChatGPT/Claude через MCP | надёжность |

Общее **ядро** (не переписывается, к нему подключаются модули):

- **Пространство** — проект (Xo'jaobod City, Paparazzi, GOLD WATER, позже клиенты).
- **Площадка** — конкретный канал/аккаунт (Telegram, Instagram, YouTube, сайт).
- **Аудитория** — контакты и их путь: откуда пришёл, куда подписан.
- **Источник** — ссылка-приглашение с меткой (какой рилс/видео привёл человека).
- **Материал** — единица контента (текст, медиа) со статусом.
- **Публикация** — что, куда, когда вышло и сколько набрало.

## 5. Правила

### 5.1 Строим рядом, а не вместо
Работающее (GENPLAN 5) не трогаем, пока новое не доказало, что лучше. Переключение — отдельный шаг с откатом.

### 5.2 Один источник правды
Код, конфигурация (без секретов), документы — только в этом репозитории. Правок руками на серверах нет. Чего нет в репозитории — того не существует.

### 5.3 Модули без номеров версий
Больше никаких «v3/v4/v5» в именах папок и служб. Имя модуля постоянное, версия — в git.

### 5.4 Секреты
Никогда не в репозитории, никогда в чате. Владелец вводит их на сервере сам. Каждая служба — свой пользователь, свой файл секретов, минимальные права.

### 5.5 Контент
- Берём факты и тренды, не чужое авторство.
- Fabrika пересказывает своими словами в стиле канала, добавляет свой юзернейм и хук.
- Материалы — только без чужих водяных знаков/логотипов; медиа без лицензии не выдаём за своё.
- Цель — уникальный контент: он дороже стоит в рекламе и безопаснее для каналов.

### 5.5.1 Пульт и PAPA HUB — закон (21.10, «раз и навсегда»)
- **PAPA HUB — не свалка.** Там лежат только материалы «Хайрли тонг». Пост группы хранится там, куда его бросили (чат пульта / ХАБ канала); в PAPA HUB копия появляется только на секунды публикации и сразу удаляется — и для обычных постов, и для рекламы, и для 🌙 Якуний поста.
- **Классический порядок, как в GENPLAN 5:** бросил пост → карточка (рубрика / время / срочно) → экран «❓ Канал · Рубрика · Время — Утверждаете?» → **«✅ Утверждаю»**. Без «Утверждаю» пост в план не встаёт. Реклама — свой шаг (✅ Разовая / 📅 Несколько дней → «✅ Утверждаю»).
- **Никаких всплывающих окошек, которые сразу исчезают.** Итог каждого нажатия («✅ Принято…», «⚠️ …») — постоянной строкой в самой карточке.
- Любая новая кнопка пульта обязана соблюдать эти три правила; тесты `TestPapaHubClean` это проверяют.

### 5.5.2 Ядро и эксперименты (30.10.2026, владелец: «отличная идея»)
- **Ядро** — письменность (только узбекская кириллица), одобрения в пультах, сетка «час = рубрика», протоколы утра/вечера/намоза, реклама.
  Меняется только записью в `docs/DECISIONS.md` (что и почему) и держится не меньше месяца.
- **Эксперимент** — новая рубрика, формат, тематический день и т. п.: срок 1 неделя, одна цифра для оценки (реакции, вступления, просмотры),
  записывается в DECISIONS с пометкой 🧪. Через неделю — цифра → оставить (переходит в ядро) или убрать.
- Ассистент, видя новое пожелание, говорит владельцу: это ядро или эксперимент.

### 5.5.3 Протокол «реклама → закрывающий пост» (30.10.2026, ядро)
- Реклама после выхода держится наверху **10 минут** (обещание клиенту) — ни пост сетки, ни 🆘 срочный раньше не выходят.
- Через 10 минут, если после рекламы ничего не вышло и пост сетки не ближе 10 минут, — **сразу закрывающий пост**:
  ближайший запланированный пост сетки на сегодня (кроме 🔒 выбранных владельцем), нет — самый старый из 📦 запаса (не склад).
- Не закрывает, если через ≤10 мин и так выйдет протокол (намаз, Кечки дайжест); в тихое окно Жумы — ждёт конца окна; посты склада не трогает.
- Работает 07:00–22:59. Код: `smart.ad_closer`, тест `tests/test_ad_closer.py`.

### 5.6 Аккаунты-активы
Instagram 238 тыс. и YouTube 575 тыс. — главный капитал. Только официальные API, никаких паролей в скриптах и имитации браузера. Лимиты платформ соблюдаются с запасом.

### 5.7 Действия владельца
Claude работает сам до упора в действие, которое может сделать только владелец (вход в его аккаунты, коды подтверждения, решения на воротах). Тогда — одно сообщение со всем нужным, а не шаг за шагом.
