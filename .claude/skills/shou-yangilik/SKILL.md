# Шоу-бизнес янгилик (шаблон №9) — эталон «Моҳим», 14.11.2026
Эталон-код: `modules/fabrika/orders/kattadavra/mohim-anons/render.py` (+ `timeline.json`, `voice_starts.json`).
Цель рубрики (владелец 14.11): зимой местные рекламодатели молчат — привлекаем внимание артистов; идёт в Инстаграм @paparazzi.uz и в Telegram КАТТА ДАВРА.

## Жёсткие правила владельца (14.11, «всегда»)
1. Материал НЕ резать, не сокращать, не переставлять. Любое изменение — только после согласования.
2. Оригинальную музыку артиста не трогать и НЕ отделять (минус не делать) — диктор идёт ПОВЕРХ. Отделять можно только чужую закадровую озвучку.
3. Вступление ролика и собственные слова артиста не перекрывать ни голосом, ни титрами.
4. Диктор — только на песне, не раньше 4 с чистой песни; не повторяет сказанное артистом. В конце песня звучит одна.
5. В конце ВСЕГДА концовка OZOD JAMOL — «без извинений», заставку канала вместо неё не предлагать.
6. Своих синтетических звуков нет. Фильтров на людях нет.
7. До монтажа согласовать: строки диктора (с номерами, кириллица), титры, приём переходов.

## Порядок
1. Изучить: кадры + звук (спектрограмма, «Уши»/whisper) → карта по секундам: вступление / слова артиста / песня / концовка. Показать таблицей.
2. Склейки исходника: `ffmpeg -vf "select='gt(scene,0.3)',metadata=print:file=-"`.
3. Голос: ветка `voice`, `$asosiy`, по одной строке на шаг, `timestamps: true`, `"hear": true`. Имя артиста проверить «Ушами».
4. Тайм-коды: ключевое слово строки (имя, «премьера», «Катта Давра») ставим ровно на склейку: `start = склейка − время слова из align.json`.
5. Картинка 1080×1920, 30 fps (исходник 720 → lanczos):
   - интро 1,5 с, вариант А (утверждён 14.11): чёрный фон + зерно, вспышка → «PAPARAZZI», вспышка → под ним «КАТТА ДАВРА», третья вспышка в белое → ролик. Без звука.
   - большие титры-вспышки (Inter Black, белые, красная черта, мягкая тень) на склейках, ~0,9 с, не больше 5 на ролик; цвет акцента — по кадрам артиста.
   - вопрос-призыв — обычной надписью выше нижней пятой части экрана (зона кнопок Reels).
   - финальное «КАТТА / ДАВРА» — «окно»: кадр виден сквозь буквы на чёрном, ниже TELEGRAM @kattadavrauz.
6. Звук: исходник как есть; под диктором −5 дБ плавно (0,5 с), потом назад; голос EQ+комп, loudnorm −13; общий лимитер. Общий loudnorm по музыке не делать.
7. Сдача: x264 crf 23 maxrate 3100k (< 50 МБ для бота); чат + outbox (оригинал документом + `*.post.json` с #ПРЕМЬЕРА) → `deliver`; очистить ветки.
