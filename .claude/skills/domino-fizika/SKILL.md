# Домино-физика PAPA (11.11.2026, первый ролик — реклама для рекламодателей OZOD JAMOL)
Движок: `modules/fabrika/domino/` — `sim.js` (физика Rapier, одинаковая в Node и браузере), `index.html` (сцена, камера, титры по голосу, карточка), `cfg.js` (ВСЁ, что меняется от заказа к заказу), `render.js` (Playwright → ffmpeg).
```bash
cd modules/fabrika/domino && npm i                     # three + @dimforge/rapier3d-compat
AUD=<папка с d1..d4.mp3 и .align.json> node render.js /tmp/s 540 960 30 --sheet=0.5,2.2,4,7.6,9.8,12,14.6   # лист кадров
AUD=... nohup node render.js out.mp4 1080 1920 30 &     # ~1,4 с/кадр, 15 с ≈ 11 мин (2 ядра, SwiftShader)
```
## Что меняется в cfg.js
- `number` — строки для поля (шрифт 5×7 в index.html, глифы `FONT`: сейчас 0 2 3 8 +; новую цифру/букву — дорисовать 5×7), `cols/rows` — размер поля (ширина строки = (символов×6−1)×2 ≤ cols).
- `voice` — фразы диктора: файл, момент старта `at`, `split` (смена половин длинной фразы), `card: true` — последняя фраза = финальная карточка; `red` — слова красным; `handle`, `under` — плашка контакта.
- Надпись на герое — `heroTex()` в index.html.
## Тайминги физики (g=100, шаг 1/240)
Толчок героя 1,15 с → падает 1,73 → змейка 3,2–7,2 (78 шт.) → клин 7,2–8,1 (14 шт., ширина растёт до ширины поля) → поле 8,2–9,8 (100 %). Длиннее змейка = позже поле (~20 костяшек/с). Голос ставить ПОД физику (`at`), не наоборот. Проверка таймингов без рендера: `node` + `buildWorld/simulate` (см. события `window.EVENTS`).
## Уроки 11.11
- Толчок героя: угловая скорость должна расти с g (g=100 → spin −6,5), иначе качнётся и встанет обратно.
- Клин: ширина растёт геометрически, толщина ПОСТОЯННАЯ — при росте толщины волна глохнет на 3-й костяшке.
- Число на поле: лицевая грань загорается по наклону (цвет экземпляра + свечение) — иначе число видно ДО падения и пропадает «раскрытие».
- Шрифт Montserrat в 13–17 пикселей превращает 0 в 8 → только свой пиксельный 5×7, масштаб 2.
- Камера сверху: up = (1,0,0) (по ходу волны), высота ~84 для поля 48×38, иначе края числа обрезаны.
- Звук: щелчки — настоящие Mixkit (pechat/klik) по моментам падения из физики (`events.json`), поле — каждое 8-е падение; удар героя — udar_490 ниже на тон. Синтетику не используем.
