# Живой анонс (образец: LOVE GO Хўжаобод, 09.11.2026)
Код-образец: `modules/fabrika/orders/lovego/otkrytie/lv_minut.py` (движок `eng.py`, сведение `mixp.py`).

## 1. Материалы
- Клипы → `raw/`, фото → `foto/`. После пачки: сколько, общая длина. Ждать «всё».
- Контакт-лист (кадр из середины каждого клипа) — РАССМОТРЕТЬ: товар по отделам, вывески, этажи, МУСОР (вёдра, бутылки, коробки) — такие кадры не брать.
- Вывески/баннеры клиента — источник фактов (акции, этажи). Не придумывать цены и условия; спорное (возврат = деньги или обмен?) — спросить.

## 2. Текст — согласовать ДО озвучки
- ~12–14 фраз, пронумерованы, узбекская кириллица, по тому, ЧТО ВИДНО на кадрах (отделы, обувь, детское, этажи) + акции + дата/время + адрес + «кутамиз».
- Длина ролика ~60–85 с. Голос НЕ на всё время: 3–4 паузы по 3–5 с под музыку.

## 3. Звук (протокол Sushi House)
- Озвучка `$asosiy`, по фразе с previous/next_text, словарь `modules/fabrika/golos/talaffuz.json` (бир соат, йотоқ, йостиқ…).
- Спорное слово → 2–3 варианта аудиофайлами → выбор владельца → в словарь.
- Музыка динамичная, лицензия (Mixkit: «Cat Walk» #371 одобрен). Сведение `mixp.py`: голос −15 LUFS + отзвук, музыка −23 со sidechain. Голос собирать в numpy (amix в ffmpeg обрезал хвост).
- Сначала mp3 владельцу → «ОК» → видео.

## 4. Картинка
- Каждая фраза — свои кадры (мужское → мужские ряды, «2-қават» → лестница/вывеска).
- Клипы: ускорение на входе (speed-ramp 2.2→1×) + whip-бросок между сценами. Короткий клип не растягивать (застывает) — добавить следующий клип или моушн.
- Название бренда в речи → АНИМИРОВАННЫЙ логотип, не стоп-кадр.
- Паузы: фото ЦЕЛИКОМ НА ВЕСЬ ЭКРАН (без рамок), каждое влетает с новой стороны (сверху/слева/снизу/справа) + вспышка на смене.
- Подписи отделов вверху жирным 3D, акции — золотые удары (УЛГУРЖИ, 7 КУН), адрес — плашка с меткой, конфетти на «кутамиз».
- Люди без фильтров. Конец — концовка OZOD JAMOL.

## 5. Сдача
- Полный файл в чат; в Telegram версия ≤ 44 МБ (2 прохода) + post.json (кириллица, жирный заголовок, этажи, акции, дата, адрес, хэштег, @канал).
- Исходники и уроки → `modules/fabrika/orders/<клиент>/README.md`.
- Рендер ~85 с ≈ 15 мин, частями по 1250 кадров (память).

## Уроки LOVE GO
- «Только музыка» без вопроса — нельзя, по умолчанию с диктором.
- Короткий ролик (28 с) — мало; владелец хочет минуту с паузами и цельными фото.
- Застывший кадр, мусор в кадре, фото в рамках, русское чтение узбекских слов — всё ловить ДО показа.
