# Разведка навыков: найти → отсеять → проверить → внедрить

## 0. Вопрос владельца «Клод, что там нового у нас про нейросети?» (06.11.2026 — так ему проще всего)
1. NEXUS `nexus_papa_task` → `github-show` (Франкфурт, только чтение): берём latest-novinki.txt («🤖 Наши инструменты»,
   каждый день 13:40) + latest-neyro.txt («📡 Нейроновинки»). Отчёт старый или пустой — внеочередной `novinki-install` не нужен,
   просто скажи «свежих новинок нет» и дату последнего выпуска.
2. Каждую новинку сам проверь на ОФИЦИАЛЬНОМ сайте сервиса (WebSearch/WebFetch) и по дате публикации. Старое и слухи — выбросить.
3. Ответ — коротко, до 3 пунктов, БЕЗ номеров: каждый пункт называется по сути новинки (выбор владельца, вариант А):
   «📰 НОВОСТЬ: Veo 4 бесплатно в телефоне» / «🛠 ВНЕДРИТЬ: новый голос ElevenLabs для роликов» / «⚠️ НА ЗАМЕТКУ: новые лимиты Claude» —
   под каждым: что это даёт нам (1 строка), расход $, официальная ссылка (кликабельно + в блоке кода).
   В конце — совет партнёра: что делать первым, плюсы/минусы, вердикт.
4. Владелец отвечает своими словами («делай новость про Veo») → 📰 готовый пост для КАТТА ДАВРА через бот (outbox `*.post.json` → `deliver`);
   🛠 — сначала смета, платное только после «да». Публиковать в канал сам не смей.
5. Ежедневная задача 14:10 («🤖 Новинки → 3 варианта для Озода») шлёт такую же карточку в бот — тем же форматом, без номеров.

Решение владельца 01.11.2026: «новинки всегда надо изучать — мы упускаем многое… если тебе не дать эти навыки,
ты так и будешь работать обычно». Отчёт сам по себе ничего не даёт — цикл заканчивается **рабочим навыком**.
Расход: $0 (GitHub API, бесплатный Gemini, рендер кодом). Платное (Higgsfield, ElevenLabs, OpenRouter) — смета и «да».

## 1. Найти (сервер делает сам)
- Таймер `papa-github.timer` — понедельник 10:00 Ташкент: GitHub-разведка (темы «Скиллы Claude», «Моушн кодом» —
  с бронью мест) + «Новинки сервисов» (ElevenLabs, Google, Kling, **Anthropic Claude**, **Remotion/HyperFrames/GSAP**…).
- Очередь навыков: `/var/lib/papa-razvedka-pub/github/navyki-queue.json` (статус «ждёт проверки»).
- Забрать в сессию: NEXUS `nexus_papa_task` → задача `github-show` (Франкфурт, авто, только чтение) → `nexus_papa_result`.
  Внеочередной заход — задача `github-now`.
- 🎓 Уроки мастеров (masters.py, тем же заходом): Gemini сам смотрит новые ролики OBSION, Риверы, Курмангалиева, Kaye, Лебедева → приёмы в отчёте и в очереди. Добавить мастера — строка в `MASTERS` (лучше с id его ролика).
- Ролики, присланные владельцем, — как прежде через `papa-video-study`.

## 2. Отсеять (10 минут, без установки)
По каждой находке одна строка: что это · полезно PAPA или мимо · где применим · расход $. Мимо — сразу отметить.
Не берём: заброшенное, без лицензии/с запретом коммерции, нужна видеокарта, накрутки/спам/парсинг личных данных.

## 3. Проверить
1. Чужой код/скилл → сначала `skill-check` (scan.py + ручной просмотр). Без этого — не ставить.
2. Один пробный кусок 3–6 с на **нашем** материале (не на демо автора). Сравнить «до / после» на одном и том же куске.
3. Оценка — воротами papa-motion (10 пунктов, среднее ≥ 8, нет < 7). Не стало лучше → «на заметку», не внедряем.

## 4. Внедрить
- Приём/правило → в `.claude/skills/papa-motion/SKILL.md` (раздел законов или «Копилка приёмов»), с источником и датой.
  Целый движок/скилл → отдельная папка в `.claude/skills/` + строка-маршрут в papa-motion.
- По правилу владельца (30.10): новинка — **эксперимент на неделю**, судим по одной цифре (оценка ворот / реакция
  зрителей). Только потом — в ядро, с записью причины в `docs/DECISIONS.md`.
- Строка в `docs/FISHKI.md` (Копилка фишек) — всегда.

## 5. Сдать владельцу
Коротко, картой «🧪 проверено / ✅ внедрено / ⚠️ на заметку», и что теперь умеем нового (одна строка на навык).
Пример ролика с новым приёмом — в чат и в Telegram (outbox → deliver), оригиналом.
