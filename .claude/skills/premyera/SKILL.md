## 0. Входные
Фото артиста (студийное; из чужого ролика — только демо, не в канал), песня (или ролик-премьера), дата, время, название, смысл песни (посвящение и т. п.), канал призыва (по умолчанию КАТТА ДАВРА @kattadavrauz).
Если прислан ролик — изучить по `papa-video-study` (кадры + «Уши»): где кончается пение и начинается диктор.

## 1. Голос (протокол Sushi House)
`voice` → ветка voice, `voice_id: "$asosiy"`, текст кириллицей, числа словами («ўн биринчи ноябрь, соат йигирмада»), `"hear": true`.
Структура текста: дата и время → «<артист> ижросидаги «<песня>» қўшиғининг (эксклюзив) премьераси» → 1–2 фразы смысла песни → «Премьерани «Катта Давра» каналида кутинг!».
Тайм-коды фраз: `silencedetect=n=-38dB:d=0.18` по mp3 голоса.

## 2. Музыка — ГЛАВНОЕ (урок 11.11)
Музыка НЕ останавливается, НЕ зацикливается, НЕ глушится в ноль.
```bash
pip install --break-system-packages -q "audio-separator[cpu]" audioread
audio-separator ORIG.wav --model_filename UVR-MDX-NET-Inst_HQ_3.onnx --model_file_dir /home/claude/sep/models --output_dir /home/claude/sep/out --output_format WAV
```
(~1,5 мин на CPU, $0, модель качается с GitHub.) Сборка: 0–V с — оригинал с пением; с V−0,8 до V−0,4 плавный переход на минус (Instrumental) по той же линии времени; минус под голосом ×0.5; конец — fade 1,2 с; голос: highpass 80, −2 дБ@250, +3.5@4k, shelf +2.5@10k, комп 3:1, loudnorm −16 → общий loudnorm −14 LUFS. Проверка «Ушами»: минус — «речи нет», итог — голос чистый.

## 3. Картинка (render_*.py: PIL + cv2, 1080×1920, 30 fps)
Сцены: A интро 0–2 с (крупно лицо, засвет, «ПРЕМЬЕРА») → B постер-карточка до V (сверху «ПРЕМЬЕРА», внизу дата/время/артист/«песня», плашка Telegram) → C под голос: дата → время → имя → красная плашка «ПЕСНЯ» → «ЭКСКЛЮЗИВ ПРЕМЬЕРА» → D карточка + смысл/посвящение по словам диктора → E призыв «Премьерани / КАТТА ДАВРА / каналида кутинг! / @kattadavrauz / дата».
Правила: только жирный шрифт (Inter Black/ExtraBold), кириллица, текст на экране = речь, тон фона под фото (navy/розовый — `tint`), пыль + зерно + блик-полоса.
Проверка: `python3 render.py stills` → лист кадров → глазами; затем полный рендер.
