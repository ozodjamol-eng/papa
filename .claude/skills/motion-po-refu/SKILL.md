# Моушн по образцу (PAPA, с 21.10.2026)

Правило: из образца берём **технику** (ритм, движение, переходы, композицию, приёмы), сюжет, слова и бренд — **свои**.
Чужие логотипы, плашки, людей, музыку образца — никогда. Расход по умолчанию 0 $ (всё кодом); Higgsfield/генерации — только со сметой и «да» владельца.

## 0. Папка проекта
```
<project>/ref/ref.mp4        образец (если их несколько — ref2.mp4… и спросить, какой главный)
<project>/src/me.mp4         наше видео (говорящая голова / съёмки товара); вертикальные клипы — src/*.mp4
<project>/audio/music.*      музыка владельца (если есть), audio/sfx/
<project>/brand/             лого (вектор/PNG), цвета, шрифты
```
Речь в нашем видео → «Уши» (скилл `papa-video-study`, шаг 2) → текст и время слов для субтитров.

## 1. Разбор образца — цифры, потом глаза
```bash
python3 -I <skill>/scripts/ref_analyze.py ref/ref.mp4 ref/an
```
Даёт: длину, склейки/с, средний план, отдельно «покадровую анимацию на двойках» (не путать со склейками), палитру (palette.png),
яркость по секундам, листы кадров каждые 0.5 с (✂ = склейка) и `analysis_auto.md` с пустыми разделами.
Затем **смотреть все листы** (Read) и там, где движение, — кадры 12 fps (`ffmpeg -ss A -t 1 -i ref.mp4 -vf fps=12,scale=480:-1,tile=4x3 …`).
Заполнить: шрифты (кириллица есть?), сетка/композиция, кривые движения, переходы, **каталог приёмов** (приём → время в образце → как у нас → инструмент), звук (BPM, удары), «берём / не берём».

## 1б. Пересказ образца владельцу: «ТОЧНО ВИЖУ / ДОДУМЫВАЮ» (с 30.10.2026, метод «обратный инжиниринг»)
До раскадровки — короткое сообщение владельцу, пункты пронумерованы:
- **✅ Точно вижу** (есть в кадрах/речи, с тайм-кодом): «0:03 текст вылетает слева с отскоком», «склейки на каждый удар», …
- **❓ Додумываю** (не видно/не слышно — моя догадка): шрифт, точная кривая, что за кадром, откуда звук, как сделан эффект.
Владелец правит пункты ❓ → только тогда раскадровка. Ошибки ролика почти всегда сидят в догадках — их убираем до работы, не после.
Правила:
1. **Маленький кусок.** Один приём / одна сцена за раз, не «весь ролик как у них». Получилось → следующий приём.
2. **Не хватает образца — попросить, а не угадывать.** Не понимаю, какой эффект/шрифт/переход он хочет → «пришлите пример (ролик, скрин, ссылку)». Владелец: «если бы ты спросил — я бы сбросил».
3. **Берём устройство, не содержимое:** движение, ритм, логика. Чужие тексты, картинки, логотипы, название — нет.
4. Доводка — обычными словами владельца («крупнее», «медленнее»), по одной правке, сверка с образцом через `compare.py`.

## 2. Раскадровка — таблица, и СТОП на «да» владельца
`storyboard.md`: `№ | время | режим (лицо/панели/графика/вставка) | что на экране | текст на экране (дословно, узбекская кириллица) | приём из каталога | звук`.
Время режется по фразам речи (Уши), удары — на долю такта музыки. Короткое сообщение владельцу: 5–8 строк сути + «делаем?». Без «да» — не рендерить.

## 3. Сборка — какой инструмент
| нужно | чем |
|---|---|
| графика поверх видео, кинетика, интерфейсы, продукт | `vizavi-motion` (HTML/Canvas, свой таймлайн) |
| бумажный коллаж, интро канала/магазина | `paper-collage-film` |
| архивный/редакционный монтаж говорящей головы | `editorial-film-edit` |
| **мебель/товар**: размеры, материалы, панели, финал | `assets/mebel_kit.js` (ниже) |
| полёт с Земли на объект | `earth-fly-in` |
Рендер покадрово: страница с `window.__comp = {width,height,fps,duration}` и `window.__seek = async (t) => {…}` →
`node <paper-collage-film>/scripts/capture.mjs comp/index.html frames --from A --to B --jpg` (2–3 воркера на 2 ядрах) → ffmpeg.
Шрифты локально: `paper-collage-film/scripts/fonts_local.py` + `static_face.py` (толстые начертания вариативных шрифтов).

## 4. Звук — по норме площадок
```bash
bash <skill>/scripts/mix_voice_music.sh video_with_voice.mp4 audio/music.mp3 out.mp4 [-18] [старт_музыки_с]
```
Голос: срез низа, мягкий компрессор. Музыка: −18 дБ и **автоприглушение под голосом** (sidechain). Итог: **−14 LUFS, пик −1 dBTP**, затухание музыки в конце 1.5 с.
Скрипт печатает итог (I и Peak) — вписать в отчёт.

## 5. Проверка перед сдачей
```bash
python3 -I <skill>/scripts/compare.py ref/ref.mp4 out.mp4 review/compare.jpg 8
```
Лист «образец ↔ наш» — смотреть глазами: техника похожа, содержание наше, ничего чужого. Плюс: длительность/fps/размер, звук −14 LUFS,
текст читается на телефоне, нет чёрных/застывших кадров, первый кадр не битый (см. прогрев ниже). Готовое видео — в чат и в Telegram (`outbox` → `deliver`).

## 6. Сохранить как скилл
Удачный ролик → его приёмы и параметры в этот скилл (или новый `/<имя>`), чтобы следующий такой же делался одной командой. Журнал — `docs/fabrika/orders/`.

## Мебельный набор `assets/mebel_kit.js` (window.MK)
Все приёмы — чистые функции времени `t` (покадровый рендер точный), цвета по умолчанию Shodiyona (`#1F3A28` зелёный, `#B8814A` дуб, `#74421E` орех, `#FBF8F1` крем; `MK.setPalette`).
- `MK.size` — размерная линия «85 см» (растёт из центра, засечки, плашка).
- `MK.pointer` — выноска: точка-пульс на детали → линия → карточка «МЕТАЛЛ КАРКАС / порошокли бўёқ».
- `MK.swatches` + `MK.TEX.wood/metal/fabric` — образцы материалов (ЭМАН, ЁНҒОҚ, МЕТАЛЛ, МАТО).
- `MK.badge` — вращающаяся звезда «ЎРТАКАШСИЗ / тўғридан-тўғри / заводдан».
- `MK.price` — ценник на нитке (цена или «ЗАВОД НАРХИ»).
- `MK.counter` — «5 ЙИЛ», «1000+ БУЮРТМА».
- `MK.panels` — **живые панели**: вертикальные клипы 9:16 в кадре 16:9, выезд по очереди, в `tf` одна раскрывается на весь кадр, соседние уезжают (решение для Shodiyona: снято вертикально, директор смотрит 16:9).
- `MK.lower` — плашка имени/должности (интервью шефа).
- `MK.subs` — субтитры по словам с подсветкой текущего (время слов — из «Ушей»).
- `MK.cta` — финал: лого, телефон печатается по цифрам с курсором, адрес/призыв.
- `MK.wipe` — шторка фирменными цветами. `MK.grain` — плёночное зерно на двойках.
- **Прогрев**: первой строкой в `__seek` — `await MK.warm()`. Без него в headless Chromium первый кадр воркера мог показать мусор из видеопамяти (кадр «плиткой»), проверено 21.10.
Демо (10 с, стул/стол нарисованы кодом): `assets/demo/` — открыть `index.html`, рендер как выше.

## Чего не делать
- Не копировать образец кадр-в-кадр, не брать из него текст, людей, логотипы, музыку.
- Не выдумывать цифры клиента (цены, сроки, «1000 клиентов») — только из брифа/речи шефа; в демо — помечать «намуна».
- Не покупать подписки на «серых» маркетплейсах (GGSel и т. п.) — риск блокировки аккаунта.
