# Полёт с Земли на объект (Google Earth Studio)

Правда, а не ИИ: настоящие снимки, точная точка. ИИ-полёты (Seedance/Kling) выдумывают местность
(в рефе 21.10 вместо Узбекистана была Америка) — для «где мы находимся» их не использовать.
Расход: 0 $. Первый раз сделано 21.10 для Shodiyona (проект «Shodiyona — полёт на цех v1» в аккаунте владельца).

## 1. Точка объекта
- Лучше всего — геометка из видео владельца (iPhone пишет её в .mov):
  ```bash
  for f in *.mov; do echo "$f $(ffprobe -v error -show_entries format_tags=com.apple.quicktime.location.ISO6709 -of csv=p=0 "$f")"; done
  ```
  Кластеры координат = разные места (цех/магазин/филиал). Дать владельцу ссылки
  `https://www.google.com/maps?q=<lat>,<lng>` и получить подтверждение, какая крыша — объект.
- Нет геометки — ссылка Google Maps от владельца или адрес.

## 2. Доступ
- Earth Studio: https://earth.google.com/studio/ — только Chrome владельца (расширение Claude in Chrome),
  аккаунт tulanovozodbek306@gmail.com (доступ одобрен 21.10). Встроенный браузер Claude не подходит:
  там нет менеджера паролей владельца. Пароль вводит только владелец.

## 3. Сборка (шаблон «Приближение к месту»)
1. «Пустой проект» → стрелка рядом → «Шаблоны» → «Приближение к месту» → «Начать»
   (если кнопка не реагирует — нажать её через javascript_tool: найти button с текстом «Начать» и .click()).
2. Поиск: ввести координаты «lat, lng» → Enter → далее; высота старта по умолчанию (вся Земля) → далее;
   длительность 9 с → галочка. Получится Земля → регион → город → вид сверху (≈ кадр 216 при 30 к/с).
3. Наклон «как дрон» в конце:
   - Ctrl+P → длительность 390 кадров (13 с), галочку «масштабировать ключи» НЕ ставить.
   - Последний кадр → «Положение камеры»: долгота/широта сместить на ~150–250 м от объекта
     (для Shodiyona: объект 40.8088, 72.3502 → камера 40.8072, 72.3519), высота ≈ земля + 180 м
     (Андижан: земля ≈ 487 м → 670 м). Изменение значения на кадре само ставит ключ.
   - «Добавить атрибуты» → «Цель камеры» → на кадре 0 задать долготу/широту объекта, высоту = земля.
     Без цели камера «гуляет» на соседнюю улицу (ошибка v2) — цель ОБЯЗАТЕЛЬНА.
   - Предпросмотр при перетаскивании цель не показывает («Цель камеры отключена») — это нормально.
   - ⚠️ У «Цели камеры» есть параметр **influence** (сила). При добавлении он = 0 — цель НЕ работает (ошибка v3 22.10:
     вышел тот же ролик, что v2). Нужно: influence 0 до кадра ≈180, плавно 1 к кадру ≈235, дальше 1.
   - Надёжнее всего править ключи не мышкой, а файлом проекта (см. 3a).
3a. Правка через файл .esp (точно и быстро):
   - Файл → Экспортировать → Проект Earth Studio → имя `<клиент>_fly.esp` → попадает в «Загрузки» владельца
     (папка подключена к сессии) → `device_stage_files`.
   - Значения в .esp нормированы: долгота = (lon+180)/360, широта = (lat+90)/180, время ключа = кадр/длительность.
     Цель камеры: `cameraTargetEffect` → `poi` (координаты) и `influence` (ключи 0→1).
   - Импорт обратно: нативное окно выбора файла нажимать нельзя. Перед Ctrl+I выполнить в странице (javascript_tool):
     перехват `HTMLInputElement.prototype.click` — если type=file, сохранить элемент в `window.__capturedInput` и не открывать окно;
     затем Ctrl+I, затем собрать `File` из текста .esp через `DataTransfer` → `input.files` → событие `change`.
     (file_upload из Chrome-расширения такие файлы не принимает.) На вопрос «Сохранить изменения?» — «Не сохранять».
4. «Визуализировать» → Video (.mp4) «Renders in the Cloud» (не jpeg: там системное окно выбора папки, его не нажать)
   → 1920×1080 → имя `<клиент>_fly_in_vN` → Submit. Ctrl+S — сохранить проект.
5. Готовое видео: письмо «Render ready for download» от donotreply-earthstudio@google.com (коннектор Gmail подключён 22.10):
   найти письмо (`search_threads` from:donotreply-earthstudio newer_than:1d) → ссылка `earth.google.com/studio/renders/download/<id>/`
   → открыть её во вкладке Chrome владельца → файл падает в `C:\Users\PAPARAZZIUZ\Downloads` → `device_stage_files`. Владелец не нужен.

## 4. Проверка (до показа владельцу)
- Кадры каждые 0,7 с + последний кадр: объект в центре, нет «ухода» на другую улицу, нет рывков.
- Подпись «Google Earth» + источник снимков (Airbus и т. п.) в кадре обязательна — не закрывать титрами.
- Ближе ~150 м снимки мягкие: финальный кадр держать на высоте крыши, дальше — живые кадры владельца.
- Готовые файлы: `D:\OZOD\10_PROJECTS\<КЛИЕНТ>\07_EARTH\`.

## 5. В монтаже
- Начало ролика: 0–7 с полёт под тихое вступление музыки, на подлёте — название города крупно;
  на последнем кадре — переход в живые кадры у входа (или «двери открываются»).
- Финал (кольцо): тот же проект, камера поднимается от объекта (ключи в обратном порядке) или
  пролёт ко второй точке (филиал) — отдельный рендер.
