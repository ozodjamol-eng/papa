# Концертная афиша с озвучкой (шаблон №8) — эталоны 13.11.2026
Эталоны: Отабек Муҳаммадзоҳид (фото → «живой постер», золото) и Хуршид Расулов (концертный клип на весь экран, «лёд»).
Код: `modules/fabrika/afisha/` — `render_otabek.py` (база: текстовые слои, блик, плашки), `render_xurshid.py` (клип на весь экран), `palette.py` (цвет по фону).
Журналы: `docs/fabrika/orders/*koncert-afisha*`.

## ‼️ Правила владельца (13.11) — не нарушать
1. **Сначала музыка.** Песня артиста звучит одна **не меньше 4 с** (ставим `V = 4.5`) — человек по песне сразу узнаёт, чей концерт. Диктор — только после этого.
2. **В конце тоже музыка.** После слов диктора песня возвращается в полную силу и стоит ещё **~3 с**, потом концовка OZOD JAMOL.
3. **У каждого артиста свой стиль.** Один и тот же цвет/шрифт двум артистам не давать (золото — один раз, второму — совсем другое).
4. **Цвет выбирает ассистент сам, по фону** — не спрашивать «А/Б/В». Сначала `palette.py`, потом палитра (см. шаг 3). «Ты должен быть лучшим аналитиком».
5. Идею, тексты, даты, телефоны берём из образца — картинку и монтаж делаем на наш лад (не перемонтаж чужого).

## 0. Входные
Образец (афиша/ролик организатора) → тексты: площадка, звание, имя, «Konsert dasturi», даты и время, телефоны.
Материал артиста: **клип** (лучше всего) или студийное фото. Песня — из клипа/образца.
Имя: написание уточнить (образец «Hurshid», владелец «Xurshid» → берём как пишет владелец, говорим об этом в отчёте).
Сверить у владельца: год концерта, телефоны. В канал — только после согласия артиста.

## 1. Изучение (кадры + «Уши», всегда)
- Раскадровка с тайм-кодами (`drawtext pts`), `hear` по звуку: есть ли диктор, где пение. Ветку `ears` очистить.
- **Реальное качество клипа:** горизонталь внутри вертикального файла (чёрные поля, полезных 720×405) — на весь экран не тянуть: сказать владельцу и попросить другой клип. Настоящая вертикаль 720×1280 → на весь экран (апскейл 1.5× + лёгкая резкость).
- Склейки клипа: `select='gt(scene,0.30)'`. **У границ сцен в клипах бывают свои вспышки/засветы** — каждый выбранный отрезок проверить кадрами (в эталоне плохие места: 17,2–18,2; 29,9–30,9; 60,8; 62–64; 69,7).
- Что нужно набрать: общий план сцены, артист крупно (поёт), артист средний ×3–4, зал/зрители ×3–4, лучи сцены (под дату), сильный финальный кадр.

## 2. Сценарий — согласовать ДО монтажа (части пронумеровать)
Текст диктора (узбекская кириллица, числа словами), 5 фраз, ~20–24 с:
1. «Ўзбекистонда хизмат кўрсатган артист — <Имя Фамилия>!» (без «Диққат, диққат» — владелец убрал)
2. «Катта концерт дастури — <площадка>.»
3. Даты и время.
4. «Маълумот учун: <первый телефон словами>.» — вслух один телефон, на экране все.
5. «Барчангизни концертда кутиб қоламиз!»
Экран = речь: лента звания → имя → «KONSERT DASTURI» → площадка (сверху) → **дата на весь экран, фон в расфокус** → плашка даты + телефоны → приглашение (сверху) → музыка ~3 с → концовка.
Надписи на экране — латиницей, как на афише артиста (исключение из правила кириллицы для рекламы артиста); пост в Telegram — кириллицей.

## 3. Цвет и шрифт по фону
```bash
python3 -I modules/fabrika/afisha/palette.py <клип|фото> 30.9,32.5 0.2,2.6 ...   # отрезки, которые идут в ролик
```
Читает главные цвета, тон, яркость, насыщенность и даёт: цвет текста, акцент, плашку, чего избегать.
- Фон цветной (насыщенность ≥ 0,12): акцент = **светлый оттенок того же тона**, плашка/подложка = тёмный оттенок того же тона. Противоположную «температуру» не брать (синий клип + золото — ошибка 13.11).
- Фон нейтральный (серое студийное фото, чёрный): акцент свободный, один (золото допустимо, если его ещё не было у другого артиста этой серии).
- Шрифт — пара к характеру: золото/классика → каллиграфия + Playfair Black; холодный концертный свет → прямой узкий Anton + Inter Black, без каллиграфии. Только жирные начертания.
- В `render_*.py` палитра задаётся заменой `R.gold_fill`, `R.GOLD`, свечения (`glow`) и цветов плашек — см. `render_xurshid.py` (ICE/NAVY).
- Людей не красить: цвет клипа не трогаем, затемняем только подложку под текст.

## 4. Звук
- Голос: ветка `voice`, `$asosiy`, одним куском, `"hear": true`; тайм-коды фраз — `silencedetect=n=-38dB:d=0.18`.
- Минус: `audio-separator … UVR-MDX-NET-Inst_HQ_3.onnx`. До диктора и после него — оригинал с пением; под голосом — минус ×0,42 (плавные переходы 0,45 с); голос −16 LUFS, общий −14.
- Шкала: `0–4,5` музыка → диктор → `+~3 с` музыка, затухание 0,5 с → концовка со своим звуком. Свои звуки не добавлять.
- Клип: звук брать одним непрерывным куском; сдвиг подобрать так, чтобы **крупный план поющего артиста совпал с песней** (в эталоне звук = клип + 14,0 с). Склейки — по ударам (`T` из автокорреляции).
- Итог проверить «Ушами»: звание, имя, даты, телефон читаются.

## 5. Картинка
- `python3 -I render_*.py stills` → лист кадров → глазами (наложение строк, края, вспышки) → `full`.
- Нижний блок: лента 1130–1150, имя, «KONSERT DASTURI», плашка даты, телефоны (низ не ниже 1840). Пока дат и телефонов нет — блок стоит ниже на 150 px и поднимается во время сцены даты.
- Фото-вариант: артист в среднем плане (фото 447 px — наезды только на надписи), арка, огни зала, лучи, пыль.
- Клип-вариант: кадры на весь экран, прямые склейки по удару, финальный кадр — замедление (`minterpolate … blend`).
- Сборка: `main.mp4` (x264 slow crf 20–21) + `OZOD_JAMOL_KONCOVKA_CHERNAYA.mp4` через `.ts` (`h264_mp4toannexb`) и `concat -c copy`; звук отдельно, `-c copy`. Файл < 50 МБ без второго сжатия.
