# «Логотип рождается» — стандарт OZOD JAMOL (утверждён владельцем 05.11.2026: «вот это другое дело»)

Эталон: `modules/fabrika/orders/ozodjamol/hamkorlar-bolvanka/build_v5_flow.py` (ролик «Бизнинг ҳамкорлар» v5, uz/ru/zh).

## Перед началом (обязательно)
1. Сверить с целью и открытыми задачами клиента: для кого ролик, на каких языках, кто «следующий партнёр» (урок 05.11: забыли LOVE GO и китайскую версию).
2. Лимит Claude: напомнить про сброс, тяжёлое — после.
3. Музыку берёт владелец (папка `modules/fabrika/motion/muzyka/`); длина ролика = длина трека. НЕ спешить: каждому логотипу ≥ 4 с, ускорение исходника ≤ 2×, в конце логотип стоит.

## Кадры (Flow, Nano Banana Pro, 0 бонусов)
- Логотип — референсом: открыть PNG на GitHub (blob-страница + JS на весь экран) → скрин → перетащить в Flow → «Добавить в запрос».
- Последний кадр: «фотореальный мир бренда + толстая 3D-скульптура логотипа exactly as designed, exact spelling» (мебель — шоурум, вода — синяя студия с бассейном, умра — бордо+золотые лучи, еда — ночной зал с гирляндами). Проверить написание букв.
- Первый кадр: правка того же изображения («keep the exact same scene… parts float apart / only empty ring / real burger layers»).
- Версии в стопке: после правки первым кадром ставится текущая версия; для последнего — открыть стопку, выбрать нужную версию в истории → «Готово».

## Видео (Omni 1.1 Flash, 9:16, 8 с, x1 = 12 бонусов, только после «да» владельца со сверкой)
- Путь 1 «Кадры»: первый+последний кадр + покадровый промпт с таймкодами (работает, когда детали похожи: диван, бургер→огонь→бейдж).
- Путь 2 «Обратная съёмка» (надёжнее для «из ничего»): только первый кадр = готовый логотип, «camera completely static, logo melts into water / dissolves into golden dust» → в монтаже `reverse`.
- ⚠️ Проверять ТОЛЬКО по скачанному файлу: превью-таймлайн Flow при перемотке показывает старый кадр.

## Скачать и собрать (сам, без владельца)
- Плитка → правый клик → Скачать → 720p (1080p — апскейл, минуты). Файлы из ~/Downloads забирать `device_stage_files`.
- Монтаж: интро OJ в тихом вступлении → партнёры по 4 с (смена на долю/удар трека, белая вспышка 0,12 с, шапка «БИЗНИНГ ҲАМКОРЛАР») → финал: логотипы-плитки в красной рамке слетаются + пульсирующее пустое место «БУ ЖОЙ — СИЗНИНГ БРЕНДИНГИЗ УЧУН» + @Ozodjamol (zh: в слот влетает логотип следующего клиента) → музыка затухает к концу трека → концовка OZOD JAMOL 2,3 с.
- Языки: uz (Cyrillic), ru, zh (шрифт Noto Sans SC 900). Шрифты только жирные.
