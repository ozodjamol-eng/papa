## Шаг 0 · Подготовка компьютера (один раз)

**0.1 Что сказать человеку сразу:**
- Нужен платный тариф Claude — минимум **Pro** (на Max больше лимитов и быстрее). Модель — **Opus 5.5**, режим
  рассуждений (effort) — **high**; для мелких правок хватит medium.
- Ролики собираются на этом компьютере: **чем мощнее компьютер, тем быстрее рендер.** Ориентир: 16 ГБ памяти и
  больше, 20 ГБ свободного места. На 8 ГБ тоже работает, но медленнее и с меньшей параллельностью.
- Remotion (движок, в котором делаем видео) бесплатен для частных лиц и компаний до 3 человек; компании крупнее
  нужна лицензия — https://www.remotion.dev/license.

**0.2 Проверь, что уже стоит** (покажи итог списком ✓ / ✗):
```
node -v        # нужен Node.js 20 или новее
npm -v
ffmpeg -version
git --version  # по желанию
```

**0.3 Поставь недостающее — после «да» человека:**
- macOS: Homebrew (https://brew.sh), затем `brew install node ffmpeg git`.
- Windows: `winget install OpenJS.NodeJS.LTS Gyan.FFmpeg Git.Git` (или установщики с https://nodejs.org и
  https://ffmpeg.org). После установки — перезапустить терминал и Claude Code: новые программы видны только в новом окне.
- Редактор кода (VS Code) — по желанию, для работы не обязателен.

**0.4 Папки проекта.** Создай рядом три папки и объясни, зачем каждая:
```
Motion/
  materials/   материалы и примеры: логотипы, фото, скринкасты, видео-образцы стилей
  work/        рабочая папка: проект Remotion, черновые рендеры, кадры для проверки — временная, чистится после ролика
  final/       готовые ролики
```
Так видео-черновики не расползаются по диску, а место легко освободить: после сдачи ролика `work/` чистится (только
с согласия человека).

**0.5 Проект Remotion** — в `work/`:
```
npx create-video@latest   # шаблон Blank, TypeScript
npm install
npx remotion studio       # откроется студия в браузере — проверка, что всё работает
```
Для 3D-сцен — пакеты той же версии, что `remotion` в `package.json`: `npx remotion add @remotion/three` (или
`npm i @remotion/three@<та же версия> three @react-three/fiber`; подробно — https://www.remotion.dev/docs/three).
Первый рендер сам скачает браузер для рендера (~100 МБ) — предупреди человека.

Проверка готовности: пробный рендер 2 секунд пустой сцены `npx remotion render <id> out/test.mp4 --frames=0-59`.
Черновики остаются в `out/` проекта внутри `work/`; в `final/` кладёшь только готовые ролики.

## Шаг 1 · Идея → СТОП

Спроси (не больше 4 вопросов за раз):
- Где выйдет ролик: Reels / Shorts (вертикаль 9:16, 1080×1920) или YouTube (16:9, 1920×1080)? Длина?
- Что зритель должен понять и почувствовать? Какой один момент должен вызвать «вау»?
- Есть ли голос или музыка? Если голос — готовая запись человека (файл) и её текст.
- Какие свои материалы есть (логотип, фото, скриншоты, видео) — их кладём в `materials/`.

**СТОП 1.** Покажи идею одним абзацем: о чём ролик, для кого, длина, формат, главный вау-момент.

## Шаг 2 · Пример и дизайн словами → СТОП

**Библиотеки примеров** — смотреть, вдохновляться и давать себе образец:
- https://promptmotion.org — галерея моушн-роликов, сделанных нейросетями, с промтами; постоянно пополняется.
- https://vincentwei1021.github.io/mg-styles-15/ — 15 стилей моушн-графики с исходниками (лицензия MIT).
- https://github.com/tuzhechen2005/opus-video-skills — приёмы видео кодом: частицы, жидкий мрамор, хром, рисованная
  анимация (лицензия MIT).

Как работать с примером:
1. Человек выбирает 1–3 примера (ссылка или файл в `materials/`). Скачивать видео — только с его согласия.
2. Разложи пример на кадры и посмотри сам: `ffmpeg -i пример.mp4 -vf "fps=2,scale=480:-1,tile=6x4" лист.png`.
3. Опиши дизайн словами: композиция, палитра (2–3 цвета + один акцент), шрифты, **2D или 3D**, свет и материалы,
   движение камеры, переходы между сценами, ритм (как часто меняется план).
4. **Не копируй один в один.** Возьми приём и улучши: под смысл ролика, под материалы человека, эффектнее примера.
   Код из примеров переносить можно только при подходящей лицензии (MIT — с сохранением уведомления).

**СТОП 2.** Покажи описание дизайна словами и предложи, что именно возьмём из примера и что сделаем лучше.

## Шаг 3 · Раскадровка → СТОП

Таблица: время или фраза голоса → сцена → что на экране → **2D или 3D** → переход к следующей → вау-приём.

- **2D** (плоские слои, текст, SVG, CSS): быстро рисуется и рендерится, хорошо для текста, интерфейсов, схем.
- **3D** (three.js): объём, свет, материалы, пролёты камеры — эффектнее, но рендер дольше и требует больше памяти.
  Смешивать можно и нужно: 3D-сцена с объёмным текстом, 2D-переход, снова 3D.
- На одну фразу — **несколько планов**: смена ракурса, 2D ↔ 3D, эффект. Пустой неподвижный кадр — не дольше 1,5 с.
- Смысл важнее украшений: вместо абстрактных фигур — настоящие логотипы (официальные SVG, не перерисовывать),
  скриншоты, материалы человека. Надписи в 3D-сцене — тоже объёмные, а не плоский текст поверх.
- Каждая сцена — свой файл (`src/scenes/s1.tsx` …): правка одной сцены не ломает другие.
- Стыки сцен продумай заранее: последний кадр сцены и первый кадр следующей совпадают (тот же цвет, предмет,
  положение) — так склейка невидима.

**СТОП 3.** Покажи раскадровку. Человек утверждает смысл и порядок сцен.

## Шаг 4 · Ключевые кадры → СТОП

По 1–2 стоп-кадра на сцену (`npx remotion still <id> кадр.png --frame=<N>`), одним листом. Видео ещё не рендеришь.
Проверь композицию, цвета, читаемость, свободные места под лицо/окно человека, если оно будет в кадре.
Самопроверка (пункты 4–6 и 9). **СТОП 4.**

## Шаг 5 · Видео-тест → СТОП

5–10 секунд самого сложного куска, в половинном размере: `npx remotion render <id> out/test-v1.mp4
--frames=<от>-<до> --scale=0.5`. Здесь проверяется движение, ритм и синхрон с голосом. Самопроверка (все пункты,
кроме звука). **СТОП 5:** человек смотрит видео, а не картинки.

## Шаг 6 · Сборка → СТОП

Весь ролик. Анимации привязаны к словам голоса или ударам музыки (по времени из записи, не «на глаз»). Звуковые
эффекты — тише голоса примерно на 7 дБ, без мелодий, которые спорят с речью. Полная самопроверка + технические
проверки ниже. **СТОП 6:** человек смотрит ролик целиком и даёт правки в форме «секунда → что → как».

Правки: меняешь только названное, перерендериваешь только изменённую сцену для проверки, новую версию всего ролика —
под новым именем.

## Шаг 7 · Финал

Рендер в полном качестве в `final/` (для телефона — лёгкая копия: `ffmpeg -i ролик.mp4 -crf 27 -preset slow
ролик_phone.mp4`). Покажи человеку. После «готово» предложи почистить `work/` (черновые рендеры) — только с согласия.

## Самопроверка — проходной балл

Перед каждым показом (шаги 4–7) оцени результат сам. Смотри **кадры глазами**: лист кадров каждые 0,5 с
(`ffmpeg -i видео.mp4 -vf "fps=2,scale=480:-1,tile=8x4" лист.png`) и ключевые моменты крупно. Каждый пункт — от 0 до 10:

| # | Пункт | 10 — это… |
|---|---|---|
| 1 | Вау в начале | первые 1,5 с цепляют даже без звука |
| 2 | Смысл | каждая сцена показывает смысл фразы, а не «просто анимацию» |
| 3 | Динамика | в фразе несколько планов, смена ракурса/2D-3D/эффекта каждые 1–2 с |
| 4 | Читаемость | одно главное слово за раз, крупно, держится ≥ 0,6 с, читается с телефона |
| 5 | Стиль и цвет | палитра выдержана, один акцент, сцена в одном стиле |
| 6 | Свет и материал | у 3D есть объём, тени, глубина; у 2D — аккуратные слои и тени |
| 7 | Стыки | склейки невидимы: совпадающие кадры, без скачков яркости и рывков |
| 8 | Синхрон | удары анимации ровно на словах или битах |
| 9 | Техника | нет мерцания текста, обрезанных элементов, артефактов; важное — в безопасной зоне |
| 10 | Звук | эффекты не заглушают голос, нет щелчков и обрывов |

**Проходной балл: среднее ≥ 8 и ни одного пункта ниже 7.** Не прошло — исправь сам (до 2 кругов) и проверь снова.
Не выходит — покажи честно: оценку, что слабо и что предлагаешь. В отчёте человеку всегда: путь к видео, оценка по
пунктам одной строкой, самое слабое место.

## Технические проверки

- **Безопасные зоны 9:16** (Reels, Shorts): главное — не ближе ~250 px к верху, ~400 px к низу и ~150 px к правому
  краю 1080×1920 (там подписи и кнопки площадки). 16:9 — поля ~96 px.
- **Частота кадров:** 30 или 60 к/с; если в ролик входят съёмки с камеры 25 к/с — 50 к/с (ровно в 2 раза).
- **Стыки:** вырежи кадры по обе стороны каждой склейки и сравни (`ffmpeg … -vf "select='eq(n\,N)'"`).
- **Шрифты** — с кириллицей; мелкий текст на медленном наезде мерцает — крупнее или без наезда.
- **Память:** тяжёлое 3D рендерь с `--concurrency=2`, чтобы компьютер не захлебнулся.
- **Громкость** готового ролика для соцсетей — около −14 LUFS (`ffmpeg -i ролик.mp4 -af ebur128 -f null -`).

## Чего не делать

- Не рендерить весь ролик ради проверки одной сцены — рендерь её кадры (`--frames`).
- Не перерисовывать чужие логотипы «похоже» — только официальные файлы.
- Не ставить программы, не скачивать и не платить без согласия человека.
- Не говорить «готово», не посмотрев результат: «на глаз норм» — не проверка.
