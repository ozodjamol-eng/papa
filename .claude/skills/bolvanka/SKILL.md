# Болванка PAPA (метод Корнева, 04.11 → навык 05.11.2026)

**Суть:** ИИ не придумывает камеру и композицию — он их получает. Мы ставим сцену в 3D из примитивов (ракурс, движение камеры, позиции людей, размеры товара), рендерим серое видео, и ИИ только превращает его в кино. Меньше брака → меньше потраченных бонусов.

## Движок
`modules/fabrika/bolvanka/` — `kit.js` (примитивы), `index.html` (сцена в браузере), `render.js` (Playwright → ffmpeg), `scenes/*.js` (одна сцена = один файл).

```bash
cd modules/fabrika/bolvanka && npm i            # только three; Playwright уже стоит в контейнере — НЕ ставить
node render.js <scene> /tmp/s 720 1280 30 --sheet=0,2,4,6,8   # лист кадров для проверки
node render.js <scene> /tmp/<scene>.mp4 720 1280 30            # видео-болванка
```

Сцена экспортирует `DURATION`, `build(THREE, scene, K)` → `{update(t)}` и `camera(t, K)` → `{pos, look, fov}`.

## Набор `kit.js` (цвета по смыслу — ИИ и владелец сразу понимают, что где)
- `stage()` — земля, небо, солнце с тенями. Окружение — серое.
- `person()` — человек 1,75 м, синий; `walk(phase, amt)`, `place(pos, yaw)`, руки `armL/armR`. «Нос» показывает, куда смотрит.
- `canister()` — баклажка 10 л, жёлтая (предмет в руках = жёлтый).
- `machineGoldWater()` — аппарат GOLD WATER в реальных пропорциях (≈1,0×1,9×0,7 м, козырёк, синяя панель цены, **полая** ниша налива 0,72–1,28 м, колонка управления); отдаёт `nozzleWorld`, `windowWorld`.
- `stream()` — струя воды (голубая). `box()` — любая коробка. `track(keys, t)` — плавные ключи камеры/движения.
- Новый товар клиента — добавить функцию в `kit.js` по фото, с размерами в метрах.

## Порядок работы
1. **Сценарий сцены согласован** с владельцем (что происходит, где камера начинает и где заканчивает, длина 6–8 с).
2. **Ставлю сцену** в `scenes/<имя>.js`. Сначала лист кадров (8 точек) → смотрю сам: герой в кадре с первого кадра? товар не закрыт телом? камера не проходит сквозь людей? финал совпадает со следующей сценой?
3. **Видео-болванка** 720×1280, 30 к/с → показать владельцу в чате (это черновик, в Telegram не слать).
4. **Первый кадр-образ** (0 бонусов): Nano Banana — кадр 0 болванки + реальное фото товара + портрет героя → фотореалистичный кадр той же композиции.
5. **Генерация** — ТОЛЬКО после сверки и «да» владельца (правило 04.11): модель, режим, болванка, первый кадр, длина, x1, цена. Порядок попыток: Omni 1.1 Flash «изменить видео» (болванка как ведущее видео, промпт «photoreal, keep camera motion and geometry exactly») → если режима нет/плохо — Omni «Кадры» (первый + последний кадр из болванки, одетые Nano Banana). Один дубль.
6. **Монтаж**: склейки по совпадению (последний кадр сцены = первый следующей), свои титры кодом, концовка OZOD JAMOL.
