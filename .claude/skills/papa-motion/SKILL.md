# PAPA Motion — законы и маршрут

Создан 01.11.2026 по решению владельца: находки (Vizavi, Rivera, OBSION…) не должны лежать порознь —
один скилл, который растёт с каждой проверенной новинкой. Порядок пополнения — `navyki-razvedka`.

**Роль (OBSION):** ты — режиссёр и аниматор студии, а не генератор слайдов.

## Законы (действуют в каждом ролике)
1. **Камера никогда не стоит** (OBSION, Vizavi): во время действия — плавный разгон/торможение, наклоны, облёты.
   Линейный zoom плоской картинки не считается. Стоит только финальный читаемый кадр.
2. **Глубина 2.5D по умолчанию** (OBSION): передний / средний / задний план с разной скоростью (параллакс),
   свет и тень. Плоский 2D — только если бриф просит. 3D — когда объём даёт «вау» (Rivera: three.js).
3. **Звук по умолчанию** (OBSION, Vizavi): музыка + звуки в ритм действию. Музыка тише голоса (владелец 28.10).
   Исключение владельца 01.11: перед логотипом OZOD JAMOL никаких своих шиммеров/вжухов — только звук ролика.
4. **Сначала идея, потом код** (Vizavi): одна нить ролика; на каждую сцену 3–5 вариантов — берём сильнейший.
   Раскадровка: время/фраза → сцена → что на экране → 2D/2.5D/3D → переход → вау (Rivera).
5. **Пружины, а не линейка**: появления и отскоки — spring/overshoot.
6. **Невидимые стыки** (Rivera): последний кадр сцены = первый следующей по цвету/предмету/положению.
7. **Первая сборка — черновик**: лист кадров каждые 0,5 с + `vizavi-motion/scripts/dead_frames.sh` →
   **ворота 10 пунктов** (вау 1,5 с · смысл · динамика · читаемость с телефона · стиль · свет/материал · стыки ·
   синхрон · техника/безопасные зоны · звук). Показ владельцу только при среднем ≥ 8 и нет пункта < 7.
   Не больше 2 кругов переделки — дальше сдать и честно сказать, что слабо.
8. **Критик — отдельный агент** (OBSION, гайд 09.11): тот, кто монтировал, свою работу не оценивает. После сборки —
   отдельный агент (Agent, свежий контекст) смотрит лист кадров каждые 0,5 с и пишет замечания С ТАЙМКОДАМИ
   («36–40 с камера замерла», «29 с подпись режется краем») + баллы по воротам; монтажёр правит ТОЛЬКО эти места.
   Критик ставит баллы только по кадрам, которые реально видел (у автора критик «оценивал» эмодзи вместо кадров).
9. **Главы по 10 с** (OBSION): длинный ролик — главами ~10 с, рендер и проверка кадров после КАЖДОЙ главы.
   В конце главы — заметка «последний кадр: что где стоит» → следующая глава начинается ровно с него (стык не виден).
   Для минутного ролика с диктором первым шагом сразу: дикторский текст на все 60 с + раскадровка на весь ролик, потом главы.

## Стили одним словом (OBSION, 11 стилей — проверены им на одном самолётике)
`лайн-бойл` (контур дрожит, будто перерисован от руки — для объяснителей) · `скетчбук` · `бумажные вырезки` (→ `paper-collage-film`) ·
`вышивка` · `пиксель` (→ `slovo-udar`) · `комикс` · `зин из газетных букв` · `плёнка` · `стекло` · `глина` · `гравюра` (у него сильнейший; стекло — слабейший).
В задании писать стиль одним словом + 1–3 скриншота дизайна: цвета, шрифты, карточки модель берёт со скриншотов (без них — «среднее»).

## Правила владельца (главнее законов автора)
- Шрифты только жирные, крупные, с кириллицей ў/қ/ғ/ҳ; титры роликов — минималистичные разреженные капсы
  (стиль Raleway, «вариант Б»), снизу, не гигантские. Узбекский — кириллица.
- Людей не красить фильтрами. Студийное качество, не «мультяшно» — кроме отдельного направления
  2D-мультик-объяснялок и аниме-серии (там стиль по брифу).
- 16:9 и 9:16 — оба всегда возможны; безопасные зоны 9:16: верх ~250 px, низ ~400 px, право ~150 px.
- **Голос (09.11, урок LOVE GO):** ролики для владельца по умолчанию С диктором (`$asosiy`), «только музыка» — только если он сам сказал. Звук — по протоколу навыка «Репортаж-ролик» (Sushi House): словарь `talaffuz.json` → фразы с previous/next_text → спорное слово 2–3 варианта аудио владельцу → сведение голос −15 / музыка −23 sidechain (`modules/fabrika/orders/lovego/otkrytie/mixp.py`) → сначала mp3 на прослушивание, потом видео.
- Реклама клиента — в конце концовка OZOD JAMOL (`docs/brand/ozod-jamol/koncovka/2s`).
- Финал не сжимать: в чат + Telegram (outbox → deliver) оригиналом. Платные движки — смета $ и «да».
