# ИИ-видео как режиссёр (уровень 3)

Источник метода: Кайсар Курмангалиев, «3 уровня ИИ-видео» (FISHKI, 30.10.2026). Владелец: «стремимся к профессиональному подходу — двигаться по-лучшему».

Главная мысль: качество даёт не модель и не «красивый промпт», а **контроль над каждой сценой**. Уровень 1 (промпт своими словами → рандом) у нас запрещён. Уровень 2 (промпт через ИИ + персонаж) — минимум. Норма — уровень 3.

## Наши инструменты (всё в Google AI Pro, 0 $ сверх подписки)
- Картинки и замена лица: **Nano Banana** (Gemini / Flow).
- Видео: **Google Flow** — Veo («Кадры → видео», «Ингредиенты»), Omni Flash для «проявления» на статичном фото.
- Монтаж, голос, музыка, текст, концовка: наш код (vizavi-motion / Remotion / ffmpeg), голоса ElevenLabs.
- Syntx, Seedance, Higgsfield — НЕ покупать без отдельного «да» и сметы.

## Порядок (каждый шаг — до генерации видео)
1. **Сюжет → раскадровка словами.** Текст/сценарий владельца нумеруем по фразам; каждой фразе — одна сцена: план (общий/средний/крупный), камера, действие, звук, эмоция. Владелец утверждает ДО картинок.
2. **Карточка героя.** Один лист: слева портрет, справа полный рост в той же одежде, нейтральный фон. Для владельца — его фото анфас/профиль/полный рост (уже есть: `docs/fabrika/orders/motivatsiya-01/refs/01–03`). Одежда фиксируется и не меняется между сценами без причины по сюжету.
3. **Реф стиля.** Кадр из фильма/рилса, который нравится владельцу → Claude описывает его словами (камера ARRI Alexa, объектив, свет, плёнка/зерно, палитра). Реф берём только как стиль — лицо из рефа НЕ переносится (если перенеслось — заменить лицо Nano Banana по карточке).
4. **Якорные кадры (сториборд).** На каждую ключевую сцену — картинка в Nano Banana (дёшево). Логика переходов: если сцена А → сцена Б непонятна зрителю, добавляем промежуточный кадр (у Кайсара стрела «летела в коней, а попала в человека» — не хватило сцены с людьми).
5. **Покадровый промпт видео** (шаблон ниже): английский, тайм-коды без разрывов, герой одним блоком, без текста/логотипов.
6. **Тест дёшево:** низкое качество/короткая длительность → проверить, что сцена «работает». Только потом финальное качество.
7. **2 дубля на сцену** по одному промпту. Сравнить: лицо похоже? одежда та же? руки/артефакты? движение живое?
8. **Монтаж лучшего** из дублей. Слабое место не показываем до конца (стрела не долетает в кадре → сразу результат). Голос/музыка/титры/концовка OZOD JAMOL — нашим кодом, не генерацией.
9. Готовое — в чат и в Telegram (outbox → deliver), оригиналом.

## Шаблон промпта (Claude пишет его сам, владельцу — в блоке для копирования)
```
[Format] 9:16 vertical (или 16:9), [N] s, cinematic, shot on ARRI Alexa 35, 24 fps, subtle film grain, natural skin tones.
[Hero] (один блок, одинаково во всех сценах) <возраст, лицо, причёска, одежда>. Same person in every shot. Use the attached character sheet.
[Shots]
0–2 s: <план>, <камера: static / slow push-in / handheld / tracking>, <действие>, <звук>.
2–4 s: ...
(минимум 6 кадров на 20 с, без пропусков по времени)
[Rules] No text, no logos, no watermarks, no subtitles. Do not change the hero's face or clothes. Do not ask questions; fill missing details yourself.
```

## Чек-лист приёмки (каждая сцена)
- Лицо = карточка; одежда/головной убор не «прыгают» между кадрами.
- Нет «мёртвых» затянутых действий (у Кайсара стрела летела 6 с — вырезать/сократить).
- Логика переходов понятна без слов.
- Людей НЕ красим цветофильтрами (правило владельца) — общий кинолук только через свет в промпте.
- Формат: 9:16 и/или 16:9 (21:9 — только если владелец сам попросит кино-формат).
