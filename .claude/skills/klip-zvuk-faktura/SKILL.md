# Клип: звук и фактура (взято частью, ⚠️)

Источник: github.com/makevoid/motion-graphics-music-video-skill (MIT, ★225, 26.09.2026). LICENSE сохранён.

**Вырезано (11.11.2026, охотник):** весь Ruby-пайплайн `mv.rb` и MCP-сервер (платная генерация через Fal: GPT Image, MiniMax H3, Stable Audio, Whisper, Demucs — ключ FAL_AI_API_KEY), Swift-VFX (только macOS), тесты, иконки. Осталось только локальное, без сети.

## Что тут
- `tools/python/sfx_mix.py music.wav cues.json out.wav` — кладёт звуки на точные секунды: обрезает тишину в начале звука (бьёт ровно в удар), ставит громкость ОТНОСИТЕЛЬНО музыки в этом месте (`rel_db`, по умолчанию −6), пиковый лимитер −1 dBFS. Музыка не меняется. cues.json: `[{"at":1.25,"wav":"pop.wav","rel_db":-5,"len":0.25,"fade":0.03}]`. Нужны numpy + ffmpeg.
- `tools/python/audio_energy.py` — энергия трека по времени (где пик/дроп) → куда ставить главный удар.
- `tools/python/cutout.py SRC OUT green|paper|none` — вырезка героя на зелёном/кремовом фоне в PNG-последовательность (НЕ нейросеть; для живого фона — наш путь rembg/SAM).
- `tools/p5/paper.js` — рваные бумажные полоски/стикеры/подписи с тенью (фактура earn.edits); `riso.js` — ризограф-зерно; `fx.js`, `lights.js` — засветы, блики, вспышки; `type.js` — текст. Это p5.js (браузер, рендер нашим Playwright).
- `references/animation-audio-vfx.md` — их правила: чистый рендер до звуков, звук по точным секундам песни, глоу после вспышки (не пересвет), не двойное зерно.

## Правила PAPA
- Шрифты — жирные (Montserrat 800–900) с ў қ ғ ҳ, а не шрифты из примеров.
- Звуки — из нашей библиотеки (Mixkit и др.) или синтез кодом (`cartoon-3d-short`), не Stable Audio (платно).
- Код запускать только наш/проверенный здесь; пробный рендер — на первом нашем ролике.
