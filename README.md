# PAPA

Экосистема для роста и монетизации собственной аудитории: YouTube и Instagram → Telegram-каналы → доход от рекламы.

| Модуль | Назначение | Статус |
|---|---|---|
| Razvedka | анализ каналов-источников и конкурентов | фаза 1 |
| Voronka | Instagram-комментарий → директ → Telegram | фаза 2 |
| GENPLAN | публикации по плану | работает (v5 на Лондоне), перенос — фаза 3 |
| Reklama | прайс, бронирование, отчёты рекламодателям | фаза 4 |
| Fabrika | ИИ-подготовка контента | фаза 5 |
| Pult | управление и наблюдение (NEXUS V2) | работает на Франкфурте |

Начинать с [`docs/PASSPORT.md`](docs/PASSPORT.md).
