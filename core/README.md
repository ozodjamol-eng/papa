# core — ядро PAPA

Общая память всех модулей: PostgreSQL, база `papa` на Лондоне (`papa-update core-install`).
Схема: `schema.sql` (идемпотентна, проверена на PostgreSQL 16: повторное применение, запрет изменения журнала событий, ограничения типов).

| Таблица | Что |
|---|---|
| spaces | пространства-проекты |
| platforms | каналы/аккаунты пространств |
| sources | ссылки с меткой (какой ролик привёл человека) |
| contacts, memberships | аудитория: только идентификаторы и путь |
| materials | контент и его статус |
| publications | что/куда/когда вышло и просмотры |
| ad_orders, ad_placements | реклама (фаза Reklama) |
| events | журнал событий, только добавление |

Сеть: пока доступ только локально на Лондоне. Доступ модулей Франкфурта через Tailscale включается отдельным шагом в фазе Voronka.
